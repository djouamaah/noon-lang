# نون — لغة برمجة عربية

**نون** لغة برمجة كاملة بصيغة عربية: كلماتها المفتاحية عربية، ودوالّها المدمجة
عربية، ورسائل أخطائها عربية، وتقبل الأرقام العربية-الهندية (`٠١٢٣`) واللاتينية
(`0123`) على السواء. مُفسِّرها مكتوب بـ Python في نحو ٢٤٠٠ سطر، بلا أي اعتماديات
خارجية.

```noon
دالة مضروب(ع) {
    إذا (ع <= ١) { أرجع ١ }
    أرجع ع * مضروب(ع - ١)
}

اطبع("مضروب ٥ =", مضروب(٥))     # ← مضروب ٥ = 120
```

---

## التشغيل

لا تحتاج إلى تثبيت شيء سوى Python 3.8 فما فوق:

```bash
python noon.py examples/hello.noon
```

```bash
python noon.py -c 'اطبع("مرحبًا يا عالم")'
```

الصدفة التفاعلية (REPL) — شغّلها بلا وسائط:

```bash
python noon.py
```

```
  ن و ن — لغة برمجة عربية · الإصدار ١٫٠
نون> متغير س = ٤
نون> س * ٣
12
نون> دالة مربّع(ع) {
  ...     أرجع ع * ع
  ... }
نون> مربّع(٧)
49
```

خيارات أخرى:

| الخيار | ما يفعله |
| --- | --- |
| `--عربي` أو `--arabic-digits` | يعرض الأعداد بالأرقام العربية-الهندية (`١٢٣`) |
| `--tokens` | يطبع الرموز اللفظية ويتوقّف |
| `--ast` | يطبع الشجرة النحوية ويتوقّف |
| `-c "شيفرة"` | ينفّذ شيفرة من سطر الأوامر |
| `-v` | رقم الإصدار |

ويمكن تثبيتها أمرًا في النظام: `pip install -e .` ثم `noon ملفي.noon`.

## جولة في اللغة

### المتغيّرات والثوابت

```noon
متغير العدّ = ١٠          # متغيّر
ثابت باي_تقريبًا = ٣٫١٤      # ثابت: تغييره خطأ
العدّ += ٥
```

التصريح إلزامي: إسناد قيمة إلى اسم غير مُعرَّف خطأ، حتى لا تُخفي غلطةٌ إملائية
متغيّرًا جديدًا. والنطاق نطاق كتلة: كل `{ ... }` نطاق مستقلّ.

### الأنواع

| النوع | مثال |
| --- | --- |
| `عدد` | `٤٢`، `3.5`، `٣٫٥`، `١٬٠٠٠` |
| `نص` | `"مرحبًا"`، `'مرحبًا'` |
| `منطقي` | `صحيح`، `خطأ` |
| `عدم` | `عدم` |
| `قائمة` | `[١، ٢، ٣]` |
| `قاموس` | `{"اسم": "زيد"، "سنّه": ٣٠}` |

الفاصلة العربية `،` والفاصلة اللاتينية `,` سواء، وكذلك `؛` و`;`.

### العمليات

```noon
٢ + ٣ * ٤          # ١٤ — الأسبقيات كما تتوقّع
٢ ** ٣ ** ٢        # ٥١٢ — الأُسّ يمين-تجميعي
٧ // ٢             # ٣ — قسمة صحيحة
٧ % ٢              # ١
٦ / ٣              # ٢ — القسمة المضبوطة بين صحيحين تبقى صحيحة
"أ" + "ب"          # "أب"
"ـ" * ٣            # "ـــ"
"عمري " + ٣٠       # "عمري 30" — العدد يُحوَّل نصًّا
٢ في [١، ٢]        # صحيح
ليس ٠              # صحيح
صحيح و خطأ         # خطأ   (أو &&)
عدم أو ٥           # ٥     (أو ||)
```

المقارنة صارمة: `١ == صحيح` ← `خطأ`، ومقارنة نصّ بعدد خطأٌ صريح لا نتيجة صامتة.

### الشروط والحلقات

```noon
إذا (الدرجة >= ٩٠) {
    اطبع("ممتاز")
} وإلا إذا (الدرجة >= ٥٠) {
    اطبع("ناجح")
} وإلا {
    اطبع("أعِد المحاولة")
}

طالما (ع > ٠) { ع -= ١ }

لكل عنصر في [١، ٢، ٣] { اطبع(عنصر) }
لكل حرف في "نون" { اطبع(حرف) }
لكل مفتاح في {"أ": ١} { اطبع(مفتاح) }
لكل ن في مدى(١، ١٠، ٢) { إذا (ن == ٧) { توقف } }
```

الأقواس حول الشرط اختيارية، والقوسان المعقوفان `{ }` إلزاميان.

### الدوال

```noon
دالة حيّ(اسم، تحية = "مرحبًا") {
    أرجع تحية + " يا " + اسم
}

اطبع(حيّ("زيد"))                  # مرحبًا يا زيد
اطبع(حيّ("زيد"، "أهلًا"))          # أهلًا يا زيد
```

الدوال قيم من الدرجة الأولى، والدالة المجهولة تُكتب بلا اسم، والإغلاق
(closure) يحفظ حالته:

```noon
دالة عدّاد(بداية) {
    متغير ع = بداية
    أرجع دالة() {
        ع += ١
        أرجع ع
    }
}

متغير التالي = عدّاد(١٠)
اطبع(التالي()، التالي())          # 11 12

اطبع(طبّق(دالة(س) { أرجع س * س }، مدى(٥)))
اطبع(رشّح(دالة(س) { أرجع س % ٢ == ٠ }، مدى(١٠)))
اطبع(اختزل(دالة(أ، ب) { أرجع أ + ب }، [١، ٢، ٣]، ٠))
```

### الأصناف

```noon
صنف شكل {
    تهيئة(اسم) { هذا.اسم = اسم }
    مساحة() { ارمِ "على كل شكل أن يحسب مساحته" }
    نص() { أرجع هذا.اسم + " مساحته " + نص(هذا.مساحة()) }
}

صنف مستطيل يرث شكل {
    تهيئة(طول_، عرض) {
        الأصل.تهيئة("مستطيل")
        هذا.طول_ = طول_
        هذا.عرض = عرض
    }
    مساحة() { أرجع هذا.طول_ * هذا.عرض }
}

اطبع(مستطيل(٣، ٤))               # مستطيل مساحته 12
```

- `تهيئة` هو الباني، و`هذا` إشارة إلى الكائن، و`الأصل` إلى الصنف الأب.
- التابع `نص()` — إن وُجد — هو ما يُطبع عند طباعة الكائن.
- كلمة `دالة` اختيارية أمام التوابع داخل الصنف.
- `من_صنف(كائن، صنف)` تفحص الانتماء عبر سلسلة الوراثة.

### الأخطاء

```noon
حاول {
    ارمِ {"نوع": "رصيد غير كافٍ"، "رسالة": "المتاح أقلّ من المطلوب"}
} امسك (خطأ_) {
    اطبع(خطأ_["رسالة"])
} أخيرًا {
    اطبع("تُنفَّذ في كل الأحوال")
}
```

أخطاء المُفسِّر نفسها تُلتقط بالطريقة ذاتها، وتصل قاموسًا فيه `نوع` و`رسالة`
و`سطر`:

```noon
حاول { اطبع(١ / ٠) } امسك (خ) { اطبع(خ["رسالة"]) }   # القسمة على صفر
```

## المرجع

### الكلمات المفتاحية

`متغير` `ثابت` `دالة` `أرجع` `إذا` `وإلا` `طالما` `لكل` `في` `توقف` `استمر`
`صحيح` `خطأ` `عدم` `و` `أو` `ليس` `صنف` `يرث` `هذا` `الأصل` `حاول` `امسك`
`أخيرًا` `ارمِ`

الهمزات موحَّدة، فـ`إذا` و`اذا` و`أرجع` و`ارجع` سواء. أما التشكيل فلا يُحذف
عمدًا، حتى تبقى `صنّف` و`رشّح` أسماءً متاحة لك لا كلماتٍ محجوزة.

### الدوال المدمجة

| الدالة | العمل |
| --- | --- |
| `اطبع(...)` | طباعة سطر |
| `اقرأ(رسالة؟)` | قراءة سطر من المستخدم |
| `طول(س)` | طول نصّ أو قائمة أو قاموس |
| `نوع(س)` | اسم النوع نصًّا |
| `نص(س)`، `عدد(س)`، `منطقي(س)`، `قائمة(س)` | تحويلات |
| `مدى(نهاية)`، `مدى(بداية، نهاية، خطوة؟)` | قائمة أعداد |
| `مجموع`، `أقصى`، `أدنى`، `مطلق`، `جذر`، `تقريب`، `أرضية`، `سقف` | حساب |
| `فرز(قائمة، مفتاح؟، تنازلي؟)`، `عكس(س)` | ترتيب |
| `طبّق(دالة، قائمة)`، `رشّح(دالة، قائمة)`، `اختزل(دالة، قائمة، ابتدائية؟)` | دوال عليا |
| `عشوائي()`، `عشوائي(حد)`، `عشوائي(من، إلى)` | عشوائيات |
| `وقت()` | الزمن بالثواني |
| `من_صنف(كائن، صنف)`، `متساويان(أ، ب)`، `تحقّق(شرط، رسالة؟)` | فحوص |
| `أرقام_عربية(صحيح)` | عرض الأعداد بالأرقام العربية-الهندية |
| `باي` | ٣٫١٤١٥٩… |

### توابع الأنواع

- **النصّ**: `طول` `قص` `تقسيم` `استبدل` `يحتوي` `يبدأ` `ينتهي` `موضع` `مقطع`
  `تكرار` `عكس` `كبير` `صغير` `أحرف`
- **القائمة**: `طول` `أضف` `احذف` `إدراج` `يحتوي` `موضع` `فرز` `عكس` `وصل`
  `مقطع` `نسخة` `مسح` `ادمج`
- **القاموس**: `طول` `مفاتيح` `قيم` `عناصر` `يحتوي` `احذف` `اجلب` `ضع` `نسخة`
  `مسح`

الفهرسة والتقطيع كما في Python: `القائمة[٠]`، `النصّ[-١]`، `القائمة[١:٣]`،
`النصّ[:٢]`.

### الصيغة (EBNF مختصرة)

```ebnf
برنامج      = { جملة } ;
جملة        = تصريح | إسناد | شرط | حلقة | دالة | صنف | "أرجع" [تعبير]
            | "توقف" | "استمر" | "ارمِ" تعبير | حاول | كتلة | تعبير ;
تصريح       = ("متغير" | "ثابت") اسم ["=" تعبير] ;
إسناد       = هدف ("=" | "+=" | "-=" | "*=" | "/=") تعبير ;
شرط         = "إذا" تعبير كتلة { "وإلا" "إذا" تعبير كتلة } ["وإلا" كتلة] ;
حلقة        = "طالما" تعبير كتلة | "لكل" اسم "في" تعبير كتلة ;
دالة        = "دالة" [اسم] "(" [وسائط] ")" كتلة ;
صنف         = "صنف" اسم ["يرث" اسم] "{" { تابع } "}" ;
حاول        = "حاول" كتلة ["امسك" ["(" اسم ")"] كتلة] ["أخيرًا" كتلة] ;
كتلة        = "{" { جملة } "}" ;
تعبير       = "أو" ⊂ "و" ⊂ مساواة ⊂ مقارنة ⊂ جمع ⊂ ضرب ⊂ أحادي ⊂ أُسّ ⊂ لاحقة ⊂ أوّلي ;
لاحقة       = أوّلي { "(" وسائط ")" | "[" تعبير | شريحة "]" | "." اسم } ;
```

## كيف يعمل المُفسِّر

مُفسِّر يمشي على الشجرة (tree-walking interpreter) في أربع مراحل:

```
النصّ ──▶ lexer.py ──▶ رموز ──▶ parser.py ──▶ شجرة ──▶ interpreter.py ──▶ تنفيذ
```

| الملف | المسؤولية |
| --- | --- |
| `noon/lexer.py` | الرموز: الأرقام العربية، النصوص، توحيد الهمزات، نهايات الجمل |
| `noon/ast_nodes.py` | عُقد الشجرة النحوية |
| `noon/parser.py` | تحليل نزولي تعاودي بأسبقيات صريحة |
| `noon/interpreter.py` | النطاقات، الاستدعاء، الأصناف، العمليات، الأخطاء |
| `noon/values.py` | الدوال والأصناف والكائنات وتحويل القيم إلى نصّ |
| `noon/builtins.py` | الدوال المدمجة وتوابع الأنواع |
| `noon/cli.py` | سطر الأوامر والصدفة التفاعلية وعرض الأخطاء |

خيارات تصميم قد تستغرب بعضها:

- **`{ }` لا `ابدأ/انتهِ`**: القوسان المعقوفان محايدان اتجاهيًّا، فلا تتعارك
  محرّرات النصّ مع اتجاه السطر عند كتابتهما، ويبقيان مألوفَين لمن يعرف لغة أخرى.
- **التصريح إلزامي**: `س = ١` بلا `متغير` خطأ، لأن الإسناد الصامت إلى اسم مكتوب
  خطأً أشهر مصادر العلل في اللغات المتساهلة.
- **لا تحذف الشدّة من الأسماء**: توحيد التشكيل كان سيسلب المبرمج أسماء مثل
  `صنّف` و`رشّح` لأنها تصير كلمات محجوزة.
- **الأعداد تُطبع باللاتينية افتراضًا** لأنها تُنسخ إلى أدوات أخرى، و`--عربي`
  تقلبها إلى `٠١٢` حين يكون الإخراج للقراءة.

## المحرّرات

في `editors/vscode/` إضافة جاهزة لـ VS Code: تلوين صيغة، ومقاطع جاهزة، وإغلاق
أقواس، وتعليق بـ `Ctrl+/`، وحدود كلمة تفهم التشكيل العربي. لا تحتاج بناءً —
انسخ المجلّد إلى `~/.vscode/extensions/` وأعِد تشغيل المحرّر
([التفاصيل](editors/vscode/README.md)).

قواعد التلوين **مولَّدة** من الكلمات المفتاحية والدوال المدمجة في المُفسِّر
نفسه، فلا تنحرف عنه:

```bash
python tools/build_grammar.py
```

ولمعاينة التلوين في المتصفّح دون تثبيت الإضافة:

```bash
python tools/preview_highlight.py examples/shapes.noon -o معاينة.html
```

## الاختبارات

٤٤ اختبارًا تغطّي المراحل الأربع، والأمثلة كلها، وقواعد التلوين:

## ما ليس فيها بعد

الوحدات والاستيراد (`استورد`)، المكرِّرات الكسولة، معالجة الملفات، الأنماط
(regex)، التوازي، ومُصحِّح أخطاء. البنية تحتمل إضافتها: كل مرحلة مفصولة عن
الأخرى، وإضافة دالة مدمجة سطرٌ واحد في `noon/builtins.py`.
