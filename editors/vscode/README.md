# إضافة «نون» لـ VS Code

تلوين صيغة لغة [نون](https://djouamaah.github.io/noon-lang/) العربية، مع مقاطع جاهزة (snippets)
وضبطًا للأقواس والتعليقات وحدود الكلمة العربية.

## التثبيت

الإضافة لا تحتاج بناءً ولا `npm`: هي ملفات تعريف فقط. انسخ المجلّد — أو أنشئ
وصلة إليه — داخل مجلّد إضافات VS Code، ثم أعِد تشغيل المحرّر:

**ويندوز**

```bash
xcopy /E /I editors\vscode "%USERPROFILE%\.vscode\extensions\noon-lang-1.2.0"
```

**لينكس/ماك**

```bash
cp -r editors/vscode ~/.vscode/extensions/noon-lang-1.2.0
```

وللتطوير على الإضافة نفسها، الوصلة الرمزية أفضل من النسخ لأن كل تعديل يظهر
بإعادة تحميل النافذة فقط (`Developer: Reload Window`):

```bash
mklink /D "%USERPROFILE%\.vscode\extensions\noon-lang" "%CD%\editors\vscode"
```

أو غلّفها ملفَّ `.vsix` وثبّتها كأي إضافة:

```bash
npx @vscode/vsce package
```

بعد التثبيت يفتح كل ملف `.noon` أو `.نون` ملوَّنًا. ولو أردت لغةً لملف بلا
امتداد: شريط الحالة ← اختيار اللغة ← «نون».

## ما تفعله

| الوجه | التفصيل |
| --- | --- |
| تلوين الصيغة | الكلمات المفتاحية والنصوص والأعداد (العربية واللاتينية) والتعليقات والأصناف والدوال والدوال المدمجة وتوابع الأنواع |
| مقاطع جاهزة | `دالة` `صنف` `صنف يرث` `إذا` `إذا وإلا` `لكل` `لكل مدى` `طالما` `حاول` `متغير` `ثابت` `اطبع` — اكتب أوّل الكلمة واضغط Tab |
| الأقواس | إغلاق تلقائي، وتحديد المطابق، وإزاحة ذكية عند `{` |
| التعليقات | `Ctrl+/` يعلّق بـ `#` |
| حدود الكلمة | النقر المزدوج يختار الاسم العربي كاملًا بتشكيله |
| الطيّ | `# منطقة` … `# نهاية` (أو `# region` … `# endregion`) |

## كيف تُولَّد القواعد

`syntaxes/noon.tmLanguage.json` **مولَّد، لا يُحرَّر يدويًّا**. مصدره الكلمات
المفتاحية والدوال المدمجة في المُفسِّر نفسه:

```bash
python tools/build_grammar.py
```

```bash
python tools/build_grammar.py --check
```

وتتحقّق الاختبارات من أن الملف محدَّث، وأن كل كلمة مفتاحية في المُفسِّر ملوَّنة،
وأن ما ليس كلمةً مفتاحية لا يُلوَّن كأنه كذلك (`صنّف` اسم لا كلمة محجوزة).

لمعاينة النتيجة في المتصفّح دون تثبيت شيء:

```bash
python tools/preview_highlight.py examples/shapes.noon -o معاينة.html
```

## حدود معروفة

- **وسائط الدوال لا تُلوَّن** لونًا خاصًّا، شأنها شأن معظم لغات VS Code التي
  تترك ذلك للتلوين الدلالي (semantic highlighting) لا لقواعد TextMate.
- **اتجاه الكتابة**: VS Code يعرض السطور بمنطق ثنائي الاتجاه لا بمحرّر عربي
  كامل، فقد يبدو موضع `{` و`(` غريبًا في سطر مختلط. يخفّ ذلك بترك مسافة حول
  الأقواس، أو بتشغيل `"editor.renderControlCharacters": true`.
- لا يوجد بعدُ خادم لغة (تكملة ذكية، انتقال إلى التعريف، أخطاء أثناء الكتابة).
  المُفسِّر يُخرج أخطاء بأرقام أسطرها، فبناء مُشكِّل مهامّ (task problem matcher)
  فوقه خطوة قريبة.
