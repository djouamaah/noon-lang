```noon
دالة مضروب(ع) {
    إذا (ع <= ١) { أرجع ١ }
    أرجع ع * مضروب(ع - ١)
}

لكل ن في مدى(١، ٦) {
    اطبع("مضروب", ن، "=", مضروب(ن))
}
```

```output
مضروب 1 = 1
مضروب 2 = 2
مضروب 3 = 6
مضروب 4 = 24
مضروب 5 = 120
```

-   :material-translate:{ .lg .middle } **عربية من أوّلها إلى آخرها**

    ---

    `إذا` و`طالما` و`دالة` و`صنف`، ودوال مثل `اطبع` و`رشّح`، وأخطاء تقول لك
    «المتغيّر «س» غير مُعرَّف» في أيّ سطر.

-   :material-numeric:{ .lg .middle } **الأرقام العربية مواطن أصلي**

    ---

    `١٢٣` و`123` و`٣٫٥` و`١٬٠٠٠` تُقرأ كلها، و`--عربي` تجعل الإخراج نفسه
    بالأرقام العربية-الهندية.

-   :material-function-variant:{ .lg .middle } **لغة حقيقية لا لعبة**

    ---

    دوال من الدرجة الأولى وإغلاق (closures)، وأصناف ووراثة، ومعالجة أخطاء
    بـ`حاول` و`امسك` و`أخيرًا`، وقوائم وقواميس بتوابعها.

-   :material-shield-check-outline:{ .lg .middle } **صارمة حيث ينبغي**

    ---

    التصريح بالمتغيّر إلزامي، والثوابت لا تتغيّر، و`١ == صحيح` خطأ، ومقارنة
    نصّ بعدد خطأٌ صريح لا نتيجة صامتة.

-   :material-microsoft-visual-studio-code:{ .lg .middle } **إضافة لـ VS Code**

    ---

    تلوين صيغة ومقاطع جاهزة، بقواعد مولَّدة من المُفسِّر نفسه فلا تنحرف عنه.

## جولة سريعة

=== "الأصناف"

    ```noon
    صنف حيوان {
        تهيئة(اسم) { هذا.اسم = اسم }
        صوت() { أرجع "..." }
        نص() { أرجع هذا.اسم + " يقول " + هذا.صوت() }
    }

    صنف قط يرث حيوان {
        صوت() { أرجع "مواء" }
    }

    اطبع(قط("مشمش"))
    ```

    ```output
    مشمش يقول مواء
    ```

=== "الإغلاق"

    ```noon
    دالة عدّاد() {
        متغير ع = ٠
        أرجع دالة() {
            ع += ١
            أرجع ع
        }
    }

    متغير التالي = عدّاد()
    اطبع(التالي()، التالي()، التالي())
    ```

    ```output
    1 2 3
    ```

=== "القوائم"

    ```noon
    متغير أعداد = مدى(١، ١١)
    متغير الزوجية = رشّح(دالة(ن) { أرجع ن % ٢ == ٠ }، أعداد)
    اطبع(الزوجية)
    اطبع("مجموع مربّعاتها:", مجموع(طبّق(دالة(ن) { أرجع ن * ن }، الزوجية)))
    ```

    ```output
    [2، 4، 6، 8، 10]
    مجموع مربّعاتها: 220
    ```

=== "الأخطاء"

    ```noon
    حاول {
        اطبع(١ / ٠)
    } امسك (خ) {
        اطبع("أمسكنا:", خ["رسالة"])
    } أخيرًا {
        اطبع("وهذا يُنفَّذ دائمًا")
    }
    ```

    ```output
    أمسكنا: القسمة على صفر
    وهذا يُنفَّذ دائمًا
    ```
