# كيف يعمل المُفسِّر

«نون» تقرأ النصّ، وتبني منه شجرة نحوية، ثم تنفّذها بأحد محرّكين يُعطيان الناتج
نفسه: **المترجِم والآلة الافتراضية** (الافتراض)، أو **المُفسِّر الشجري** الذي يمشي
على الشجرة ويزور عُقدها واحدة واحدة (بـ`--شجرة`). هذه الصفحة عن المراحل المشتركة
وعن المُفسِّر الشجري؛ وللمترجِم صفحته: [المترجِم والآلة الافتراضية](compiler.md).

| المرحلة | الملف | تأخذ | تُعطي |
| --- | --- | --- | --- |
| ١. التحليل اللفظي | `noon/lexer.py` | نصّ البرنامج | قائمة رموز |
| ٢. التحليل النحوي | `noon/parser.py` | الرموز | شجرة نحوية (`noon/ast_nodes.py`) |
| ٣. التنفيذ | `noon/compiler.py` و`noon/vm.py`، أو `noon/interpreter.py` | الشجرة | الأثر: طباعة، قيم، أخطاء |
| ٤. الواجهة | `noon/cli.py` | ملف أو صدفة | تشغيل وعرض الأخطاء |

## ١. المُحلِّل اللفظي

يمرّ على النصّ حرفًا حرفًا ويجمعه رموزًا: `إذا` كلمة مفتاحية، و`س` اسم، و`١٢`
عدد، و`>=` عملية. هنا تُحسم مسائل عربية كثيرة:

- **الأرقام**: `٠`–`٩` و`۰`–`۹` تُحوَّل إلى أرقامها اللاتينية قبل تكوين العدد،
  و`٫` فاصلة عشرية، و`٬` يُتجاهل.
- **الكلمات المفتاحية**: يُوحَّد رسم الهمزات والألف المقصورة والتاء المربوطة ثم
  يُبحث في جدول الكلمات. التشكيل لا يُحذف، فـ`صنّف` لا تطابق `صنف`.
- **نهايات الجمل**: السطر الجديد رمز `NEWLINE`، إلا داخل `( )` و`[ ]` فيُتجاهل،
  و`؛` تُعامَل مثله.

```bash
python noon.py --tokens -c "متغير س = ٣٫٥"
```

```text
Token(VAR, 'متغير', سطر 1)
Token(IDENT, 'س', سطر 1)
Token(ASSIGN, '=', سطر 1)
Token(NUMBER, 3.5, سطر 1)
Token(NEWLINE, '\\n', سطر 1)
Token(EOF, None, سطر 1)
```

## ٢. المُحلِّل النحوي

مُحلِّل نزولي تعاودي (recursive descent): لكل قاعدة في [الصيغة](../reference/grammar.md)
دالة. الأسبقيات مرسومة في سلسلة الاستدعاءات نفسها — `logic_or` تنادي
`logic_and`، وهذه تنادي `equality`، وهكذا حتى `primary` — فالعملية الأقوى
تُبنى أعمق في الشجرة.

والنتيجة شجرة من عُقد بسيطة، كلٌّ منها صنف في `ast_nodes.py` له حقوله ورقم سطره:

```bash
python noon.py --ast -c "اطبع(١ + ٢ * ٣)"
```

```text
Program(body=[ExprStmt(expr=Call(callee=Identifier(name='اطبع'), args=[Binary(op='+', left=Literal(value=1), right=Binary(op='*', left=Literal(value=2), right=Literal(value=3)))]))])
```

## ٣. التنفيذ

`Interpreter` يزور العُقد: لكل نوع جملة تابع `exec_…`، ولكل نوع تعبير تابع
`eval_…`. `eval_Binary` مثلًا يحسب الطرفين ثم يسلّمهما إلى `binary()`.

**النطاقات** سلسلة من `Environment`: كل كتلة تصنع بيئة أبوها البيئة المحيطة،
والبحث عن اسم يصعد السلسلة. والدالة تحمل البيئة التي عُرِّفت فيها — وهذا كل
ما يحتاجه الإغلاق.

**التحكّم في التدفّق** — `أرجع` و`توقف` و`استمر` — استثناءات Python داخلية
(`ReturnSignal`…) تصعد إلى الحلقة أو الدالة التي تلتقطها. و`ارمِ` استثناء
`NoonThrow` يحمل القيمة المرميّة إلى `امسك`.

### الدلالات منفصلة عن التنفيذ

معنى العمليات على القيم — الجمع، والمقارنة، والفهرسة، والوصول إلى الأعضاء،
وعرض القيم نصًّا — في `noon/runtime.py`، في صنف `Runtime` يرثه المحرّكان كلاهما.
هكذا يبقى «ماذا تعني `+`» في مكان واحد، مستقلًّا عن «كيف يُنفَّذ البرنامج»، ولا
يستطيع المحرّكان أن يختلفا فيه. والدوال المدمجة تستقبل المحرّك باسم `interp` ولا
تستعمل منه إلا هذه الواجهة، فتعمل مع الاثنين دون تعديل.

| الملف | ما فيه |
| --- | --- |
| `noon/runtime.py` | العمليات على القيم وعرضها |
| `noon/values.py` | الدوال والأصناف والكائنات، والصدق والمساواة |
| `noon/builtins.py` | الدوال المدمجة وتوابع النصوص والقوائم والقواميس |
| `noon/errors.py` | الأخطاء وإشارات التحكّم |

## ٤. الواجهة

`cli.py` يقرأ الملف (UTF-8، مع تجاهل BOM)، ويضبط مجاري الإدخال والإخراج على
UTF-8 حتى في طرفية ويندوز، ويختار المحرّك، ويعرض الخطأ مع سطره وموضعه. والصدفة
التفاعلية تجمع الأسطر حتى تكتمل الأقواس، وتُبقي محرّكًا واحدًا حيًّا بين الأسطر.

## تضمين «نون» في برنامج Python

```python
import io
from noon import VM, NoonError

out = io.StringIO()
engine = VM(out=out)          # أو Interpreter(out=out)
try:
    engine.run('اطبع("من داخل بايثون", ٢ ** ١٠)')
except NoonError as error:
    print("خطأ:", error)

print(out.getvalue())        # من داخل بايثون 1024
```
