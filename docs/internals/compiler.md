# المترجِم والآلة الافتراضية

لـ«نون» محرّكا تنفيذ يُعطيان الناتج نفسه:

| المحرّك | كيف يعمل | متى |
| --- | --- | --- |
| **المترجِم والآلة الافتراضية** | يترجم الشجرة النحوية إلى بايت-كود، ثم تنفّذه آلة مكدّسية | الافتراض |
| **المُفسِّر الشجري** | يمشي على الشجرة النحوية وينفّذ كل عقدة | بـ`--شجرة` |

```bash
python noon.py برنامج.noon            # المترجِم والآلة
python noon.py --شجرة برنامج.noon     # المُفسِّر الشجري
```

الآلة **أسرع بنحو الضعف** في المتوسّط، وتبلغ **عمق تعاود أكبر بكثير**، وتحفظ
البرنامج المُترجَم في ملف. والمُفسِّر الشجري أبسط وأقرب إلى الشجرة، فهو **المرجع**:
كل ما تفعله الآلة يُقارَن بما يفعله هو.

## من النصّ إلى التنفيذ

| المرحلة | الملف | تأخذ | تُعطي |
| --- | --- | --- | --- |
| التحليل اللفظي والنحوي | `lexer.py`، `parser.py` | نصّ البرنامج | شجرة نحوية |
| الترجمة | `compiler.py` | الشجرة | دالة مُترجَمة: تعليمات وثوابت وجداول |
| التنفيذ | `vm.py` | الدالة المُترجَمة | الأثر |

والمرحلتان الأوليان مشتركتان بين المحرّكين، وكذلك معنى العمليات على القيم
(`runtime.py`): الجمع والفهرسة والمقارنة وعرض القيم موجودة مرّة واحدة.

## كيف يبدو البايت-كود

`--فكّك` تعرض ما أنتجه المترجِم:

```bash
python noon.py --فكّك مضروب.noon
```

```noon
دالة مضروب(ن) {
    إذا (ن <= ١) { أرجع ١ }
    أرجع ن * مضروب(ن - ١)
}
اطبع(مضروب(٥))
```

           2  عرّف_مستبدلًا          0 (مضروب)
    5      4  ادفع_عامًّا            1 (اطبع)
           6  ادفع_عامًّا            0 (مضروب)
           8  ادفع_ثابتًا            5

          12  نادِ                   1
          14  أسقط
          16  ادفع_ثابتًا            عدم

══ دالة مضروب(ن) ══  خانات: 1
    2      0  ادفع_محلّيًّا          0 (ن)
           2  ادفع_ثابتًا            1
           4  عملية                  <=
           6  اقفز_إن_كذب            ← 12
           8  ادفع_ثابتًا            1

الأعمدة: رقم السطر في المصدر، وموضع التعليمة، واسمها، ووسيطها. الآلة **مكدّسية**:
`ادفع_محلّيًّا 0` تضع قيمة `ن` على المكدس، و`ادفع_ثابتًا 1` تضع الواحد، و`عملية <=`
تأخذهما وتضع النتيجة، و`اقفز_إن_كذب ← 12` تأخذ النتيجة وتقفز إن كانت كاذبة.

## الأسماء تُحَلّ قبل التشغيل

في المُفسِّر الشجري يُبحث عن كل اسم في سلسلة من القواميس كلّما نُفِّذ. المترجِم
يحسم وقت الترجمة من أين يأتي كل اسم، فيُصدر التعليمة المناسبة:

| الاسم | التعليمة | المثال أعلاه |
| --- | --- | --- |
| محلّي في الدالة | `ادفع_محلّيًّا`: خانة مرقّمة في مصفوفة الإطار | `ن` خانة 0 |
| عامّ (المستوى الأعلى والدوال المدمجة) | `ادفع_عامًّا`: بحث في قاموس | `مضروب`، `اطبع` |
| محلّي التقطته دالة داخلية | `ادفع_خليّة` | انظر أدناه |
| من دالة محيطة | `ادفع_حرًّا` | انظر أدناه |

المستوى الأعلى من البرنامج عامّ، فتبقى تعريفات [الصدفة التفاعلية](../getting-started/repl.md)
حيّةً بين أسطرها.

## الإغلاق والخلايا

المتغيّر الذي تلتقطه دالة داخلية لا يبقى خانة عادية: يُوضع في **خليّة**، صندوق
صغير تشير إليه الدالتان، فإذا غيّرته إحداهما رأت الأخرى التغيير.

```noon
دالة عدّاد() {
    متغير ع = ٠
    أرجع دالة() {
        ع += ١
        أرجع ع
    }
}
```

```text
══ دالة عدّاد() ══  خانات: 1
    2      0  ادفع_ثابتًا            0
           2  هيّئ_خليّة             0 (ع)
    3      4  اصنع_دالة              <دالة مجهولة>
           6  أرجع
           8  ادفع_ثابتًا            عدم
          10  أرجع

══ دالة مجهولة() ══  خانات: 0 · متغيّرات حرّة: ع
    4      0  ادفع_حرًّا             0 (ع)
           2  ادفع_ثابتًا            1
           4  عملية                  +
           6  خزّن_حرًّا             0 (ع)
    5      8  ادفع_حرًّا             0 (ع)
          10  أرجع
          12  ادفع_ثابتًا            عدم
          14  أرجع
```

`هيّئ_خليّة` تضع `ع` في خليّة، و`اصنع_دالة` تُعطي الدالة المجهولة تلك الخليّة
نفسها، فتقرؤها `ادفع_حرًّا` وتكتبها `خزّن_حرًّا`.

وثلاث مسائل تجعل هذا أصعب ممّا يبدو، وكلها لازمة ليطابق المترجِمُ المُفسِّرَ:

**متى يُعرف أن متغيّرًا مُلتقَط؟** بعد أن تُترجَم الدالة الداخلية، أي بعد أن
صدرت تعليمات قراءته في الدالة المحيطة. فيحفظ المترجِم مواضع تلك التعليمات،
ويحوّلها إلى تعليمات خلايا حين يُلتقط المتغيّر.

**دالة داخلية تستعمل متغيّرًا عُرِّف بعدها.** المُفسِّر يبحث عن الاسم وقت التنفيذ،
فتجد الدالة الداخلية متغيّرًا عُرِّف بعد تعريفها ما دام قد عُرِّف قبل ندائها —
وعليه يقوم التعاود المتبادل بين دالتين محلّيتين. فيسجّل المترجِم كل إحالة من دالة
داخلية إلى اسم خارجها، ويُعيد توجيهها إن ظهر لاحقًا تعريف أقرب.

**كل دورة حلقة متغيّرات جديدة.** الدالة المصنوعة في الدورة الثالثة تتذكّر قيمة
الدورة الثالثة لا الأخيرة. فتُفرَغ خلايا النطاق في أوّل كل دورة
(`ادخل_نطاقًا`)، وتُحذف هذه التعليمة بعد الترجمة من كل نطاق لا خلايا فيه.

## «أخيرًا» على كل طريق خروج

`أخيرًا` تُنفَّذ مهما خرج التنفيذ من `حاول`. المترجِم يضع نسخة من كتلتها على كل
طريق خروج:

- بعد نجاح المحاولة أو الالتقاط.
- في طريق الخطأ، ثم تُعيد `نهاية_أخيرًا` رميه.
- قبل كل `أرجع` و`توقف` و`استمر` تعبر الكتلة، مع إزالة مُعالِجات المحاولة التي
  تغادرها.

والخطأ الذي يقع داخل دالة مدمجة نادت دالةً من دوالّك — `طبّق` أو `فرز` بدالة
مفتاح — يُلتقط بـ`امسك` خارجها كما في المُفسِّر.

## الملفات المُترجَمة

```bash
python noon.py --ترجم برنامج.noon            # يكتب برنامج.noonc
python noon.py --ترجم برنامج.noon -o آخر.noonc
python noon.py برنامج.noonc                  # يشغّله دون ترجمة
python noon.py --فكّك برنامج.noonc
```

ملف `.noonc` يبدأ بالبايتات `NOONC` ثم رقم إصدار الصيغة، ثم الدالة المُترجَمة
مُسلسَلةً بـ`marshal` من مكتبة Python القياسية. الملف المُترجَم بإصدار صيغة آخر
يُرفض برسالة تطلب إعادة ترجمته.

!!! warning "لا تشغّل ملفًّا مُترجَمًا من مصدر لا تثق به"
    `marshal` لم يُصمَّم لبيانات عدائية: ملف مُعَدّ بخبث قد يُسقط Python نفسه.
    الملفات المُترجَمة لتسريع برامجك أنت، لا لتوزيع برامج على غيرك.

## الأداء

```bash
python tools/benchmark.py
```

يشغّل خمسة برامج في المحرّكين بالتناوب، ويأخذ أفضل زمن لكلٍّ، ويتحقّق أن
ناتجيهما واحد قبل عرض الأرقام:

| البرنامج | المُفسِّر الشجري | الآلة | التسريع |
| --- | ---: | ---: | ---: |
| تعاود (فيبوناتشي ٢٢) | 704 م.ث | 253 م.ث | 2.8× |
| حلقات وحساب في المستوى الأعلى | 2770 م.ث | 1207 م.ث | 2.3× |
| إغلاق ودوال عليا | 326 م.ث | 158 م.ث | 2.1× |
| أصناف وتوابع | 763 م.ث | 395 م.ث | 1.9× |
| غربال الأعداد الأوّلية | 1158 م.ث | 662 م.ث | 1.8× |

المتوسّط الهندسي **2.1×**، على Python 3.14 في جهاز واحد؛ فالأرقام المطلقة
تختلف من جهاز إلى آخر، والنسب أثبت منها. والترجمة نفسها تستغرق أقلّ من
ميلي ثانية لكل برنامج منها.

**عمق التعاود** لا يحدّه في الآلة مكدّسُ Python، فتبلغ ٥٠٠٠ استدعاء متداخل،
بينما يتوقّف المُفسِّر الشجري دون الألف.

## التطابق مع المُفسِّر

المُفسِّر الشجري هو المرجع، و`tests/test_vm.py` يُلزم الآلة بمطابقته حرفًا بحرف
— في الناتج وفي نصّ الخطأ ورقم سطره:

- **اختبارات اللغة كلها** تُشغَّل مرّة ثانية على الآلة.
- **كل كتلة شيفرة في هذا التوثيق** تُشغَّل في المحرّكين ويُقارن ناتجاهما.
- **برامج صعبة** في `tests/differential_cases.py` تستهدف ما يختلف فيه عادةً
  المترجِم عن المُفسِّر: الإغلاق داخل الحلقات، والتعريف بعد الاستعمال، و«أخيرًا»
  مع `أرجع` و`توقف`، والأخطاء العابرة للدوال المدمجة.

والفرق الوحيد المقصود هو عمق التعاود أعلاه.

## التعليمات

كل تعليمة عددان: رمزها ووسيطها. هذه أسماؤها كما تظهر في `--فكّك`:

| التعليمة | عملها |
| --- | --- |
| `ادفع_ثابتًا` | تدفع ثابتًا من جدول ثوابت الدالة |
| `ادفع_محلّيًّا`، `خزّن_محلّيًّا` | تقرأ خانة محلّية أو تكتبها |
| `ادفع_خليّة`، `خزّن_خليّة`، `هيّئ_خليّة` | الشيء نفسه لمتغيّر مُلتقَط، و`هيّئ` عند تصريحه |
| `ادفع_حرًّا`، `خزّن_حرًّا` | متغيّر من دالة محيطة |
| `ادفع_عامًّا`، `خزّن_عامًّا` | متغيّر عامّ |
| `عرّف_عامًّا`، `عرّف_ثابتًا` | «متغير» و«ثابت» في المستوى الأعلى |
| `عرّف_مستبدلًا` | «دالة» و«صنف» في المستوى الأعلى: تستبدل ما سبق |
| `أسقط`، `بادل` | تُسقط القمّة أو تبادل العنصرين العلويين |
| `عملية` | عملية ثنائية (`+`، `<`، `في`…) |
| `سالب`، `موجب`، `ليس` | العمليات الأحادية |
| `اقفز` | قفزة غير مشروطة |
| `اقفز_إن_كذب`، `اقفز_إن_صدق` | قفزة مشروطة تستهلك القيمة |
| `اقفز_إن_كذب_مُبقيًا`، `اقفز_إن_صدق_مُبقيًا` | لـ«و» و«أو»: تُبقي القيمة لأنها نتيجة التعبير |
| `نادِ`، `أرجع` | الاستدعاء والعودة |
| `اصنع_دالة` | تصنع دالة وتعطيها خلاياها المُلتقَطة |
| `ابنِ_قائمة`، `ابنِ_قاموسًا`، `ابنِ_صنفًا` | تبني من عناصر المكدس |
| `اجلب_بالفهرس`، `ضع_بالفهرس`، `اقتطع` | الفهرسة والتقطيع |
| `اجلب_عضوًا`، `ضع_عضوًا`، `الأصل` | الأعضاء، و«الأصل» داخل التوابع |
| `ابدأ_التكرار`، `التالي_أو_اقفز` | حلقة «لكل» |
| `ارمِ`، `هيّئ_المحاولة`، `أنهِ_المحاولة`، `نهاية_أخيرًا` | الأخطاء |
| `ادخل_نطاقًا` | تُفرغ خلايا نطاق في أوّل كل دورة |
| `ارمِ_خطأ` | خطأ عرفه المترجِم مسبقًا، يقع حين يُنفَّذ موضعه كما في المُفسِّر |

الترقيم جزء من صيغة ملفات `.noonc`: التعليمة الجديدة تُضاف في آخر القائمة،
ويُرفع رقم إصدار الصيغة.
