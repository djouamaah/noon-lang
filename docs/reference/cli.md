# سطر الأوامر

```text
python noon.py [ملف] [-c شيفرة] [--شجرة] [--ترجم [-o مسار]] [--فكّك]
               [--عربي] [--tokens | --ast] [-v]
```

بعد `pip install -e .` يصير الأمر `noon` بالخيارات نفسها.

## طرق التشغيل

| الأمر | ما يُنفَّذ |
| --- | --- |
| `python noon.py برنامج.noon` | الملف |
| `python noon.py برنامج.noonc` | ملف [مُترجَم](../internals/compiler.md#الملفات-المترجمة) مسبقًا |
| `python noon.py -c "اطبع(١)"` | الشيفرة المكتوبة بعد `-c` |
| `echo "اطبع(١)" \| python noon.py` | ما يصل من الدخل القياسي |
| `python noon.py` | [الصدفة التفاعلية](../getting-started/repl.md) |

يُنفَّذ كل ذلك افتراضًا **بالمترجِم والآلة الافتراضية**. انظر
[المترجِم والآلة الافتراضية](../internals/compiler.md) للفرق بين المحرّكين.

## الخيارات

| الخيار | عمله |
| --- | --- |
| `--شجرة`، `--tree` | التنفيذ بالمُفسِّر الشجري بدل المترجِم؛ الناتج واحد |
| `--ترجم`، `--compile` | ترجمة البرنامج إلى ملف `.noonc` بجانبه دون تشغيله |
| `-o`، `--output` | مسار الملف المُترجَم مع `--ترجم`؛ لازم مع `-c` |
| `--فكّك`، `--dis` | عرض البايت-كود بصيغة مقروءة دون تشغيل، لمصدر أو لملف `.noonc` |
| `--عربي`، `--arabic-digits` | تُطبع الأعداد بالأرقام العربية-الهندية: `١٢٣٫٥` |
| `--tokens` | يطبع الرموز التي أنتجها المُحلِّل اللفظي ولا يُنفِّذ |
| `--ast` | يطبع الشجرة النحوية ولا يُنفِّذ |
| `-v`، `--version` | رقم الإصدار |
| `-h`، `--help` | المساعدة |

`--tokens` و`--ast` و`--فكّك` مفيدة لفهم كيف تُقرأ شيفرتك وتُترجَم:

```bash
python noon.py --tokens -c "اذا س > ١ { }"
```

```text
Token(IF, 'اذا', سطر 1)
Token(IDENT, 'س', سطر 1)
Token(GT, '>', سطر 1)
Token(NUMBER, 1, سطر 1)
Token(LBRACE, '{', سطر 1)
Token(RBRACE, '}', سطر 1)
Token(NEWLINE, '\\n', سطر 1)
Token(EOF, None, سطر 1)
```

## الترجمة إلى ملف

```bash
cd examples
python ../noon.py --ترجم fib.noon
```

```text
تُرجم إلى fib.noonc (2725 بايت)
```

والملف المُترجَم يُشغَّل ويُفكَّك مثل المصدر، لكنه لا يُشغَّل بـ`--شجرة` (المُفسِّر
الشجري يحتاج الشجرة النحوية)، ولا يقبل `--ترجم` أو `--tokens` أو `--ast`.

## الأخطاء ورموز الخروج

عند الخطأ يُطبع على مجرى الأخطاء نوعه ورقم سطره، ثم السطر المخالف وسهم تحت
موضعه (للأخطاء النحوية):

```text
خطأ نحوي [سطر 2]: تعبير غير متوقّع: «)» (برنامج.noon)
  اطبع(س + )
           ^
```

| الرمز | المعنى |
| --- | --- |
| `0` | انتهى البرنامج بنجاح |
| `1` | خطأ نحوي، أو خطأ تشغيل، أو قيمة مرميّة لم تُلتقط، أو ملف مُترجَم تالف |
| `2` | الملف غير موجود، أو خيارات لا تجتمع (مثل `--شجرة` مع `--ترجم`) |
| `130` | أُوقف بـ ++ctrl+c++ |

فيصلح في السكربتات: `python noon.py فحص.noon && echo نجح`.
