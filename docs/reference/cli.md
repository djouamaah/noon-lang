# سطر الأوامر

```text
python noon.py [ملف] [-c شيفرة] [--عربي] [--tokens | --ast] [-v]
```

بعد `pip install -e .` يصير الأمر `noon` بالخيارات نفسها.

## طرق التشغيل

| الأمر | ما يُنفَّذ |
| --- | --- |
| `python noon.py برنامج.noon` | الملف |
| `python noon.py -c "اطبع(١)"` | الشيفرة المكتوبة بعد `-c` |
| `echo "اطبع(١)" \| python noon.py` | ما يصل من الدخل القياسي |
| `python noon.py` | [الصدفة التفاعلية](../getting-started/repl.md) |

## الخيارات

| الخيار | عمله |
| --- | --- |
| `--عربي`، `--arabic-digits` | تُطبع الأعداد بالأرقام العربية-الهندية: `١٢٣٫٥` |
| `--tokens` | يطبع الرموز التي أنتجها المُحلِّل اللفظي ولا يُنفِّذ |
| `--ast` | يطبع الشجرة النحوية ولا يُنفِّذ |
| `-v`، `--version` | رقم الإصدار |
| `-h`، `--help` | المساعدة |

`--tokens` و`--ast` مفيدان لفهم كيف تُقرأ شيفرتك:

```bash
python noon.py --tokens -c "اذا س > ١ { }"
```

```text
Token(IF, 'اذا', سطر 1)
Token(IDENT, 'س', سطر 1)
Token(GT, '>', سطر 1)
Token(NUMBER, 1, سطر 1)
Token(LBRACE, '{', سطر 1)
Token(RBRACE, '}', سطر 1)
Token(NEWLINE, '\\n', سطر 1)
Token(EOF, None, سطر 1)
```

## الأخطاء ورموز الخروج

عند الخطأ يُطبع على مجرى الأخطاء نوعه ورقم سطره، ثم السطر المخالف وسهم تحت
موضعه (للأخطاء النحوية):

```text
خطأ نحوي [سطر 2]: تعبير غير متوقّع: «)» (برنامج.noon)
  اطبع(س + )
           ^
```

| الرمز | المعنى |
| --- | --- |
| `0` | انتهى البرنامج بنجاح |
| `1` | خطأ نحوي، أو خطأ تشغيل، أو قيمة مرميّة لم تُلتقط |
| `2` | الملف غير موجود |
| `130` | أُوقف بـ ++ctrl+c++ |

فيصلح المُفسِّر في السكربتات: `python noon.py فحص.noon && echo نجح`.
