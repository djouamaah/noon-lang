# الكلمات المفتاحية

الكلمات المحجوزة في «نون» خمس وعشرون، لا تصلح أسماءً للمتغيّرات أو الدوال.

## التصريح

| الكلمة | عملها | انظر |
| --- | --- | --- |
| `متغير` | تصريح بمتغيّر | [المتغيّرات](../guide/variables.md) |
| `ثابت` | تصريح بثابت | [الثوابت](../guide/variables.md#الثوابت) |
| `دالة` | تعريف دالة أو دالة مجهولة | [الدوال](../guide/functions.md) |
| `صنف` | تعريف صنف | [الأصناف](../guide/classes.md) |
| `يرث` | وراثة صنف من آخر | [الوراثة](../guide/classes.md#الوراثة) |

## التحكّم في التدفّق

| الكلمة | عملها |
| --- | --- |
| `إذا` | شرط |
| `وإلا` | بديل الشرط، و`وإلا إذا` لسلسلة شروط |
| `طالما` | حلقة شرطية |
| `لكل` | حلقة على عناصر، مع `في` |
| `في` | في `لكل`، وعملية الانتماء `س في ق` |
| `توقف` | الخروج من الحلقة |
| `استمر` | الانتقال إلى الدورة التالية |
| `أرجع` | إنهاء الدالة وإرجاع قيمة |

## الأخطاء

| الكلمة | عملها |
| --- | --- |
| `حاول` | كتلة قد يقع فيها خطأ |
| `امسك` | التقاط الخطأ |
| `أخيرًا` | كتلة تُنفَّذ في كل الأحوال |
| `ارمِ` | رمي قيمة خطأً |

## القيم

| الكلمة | معناها |
| --- | --- |
| `صحيح` | القيمة المنطقية الصادقة |
| `خطأ` | القيمة المنطقية الكاذبة |
| `عدم` | لا قيمة |
| `هذا` | الكائن الحالي داخل تابع |
| `الأصل` | الصنف الأب داخل تابع |

## العمليات المنطقية

| الكلمة | بديلها الرمزي |
| --- | --- |
| `و` | `&&` |
| `أو` | `\|\|` |
| `ليس` | `!` |

## صيغ الكتابة المقبولة

الكلمات المفتاحية تتسامح في رسم الهمزة والألف المقصورة والتاء المربوطة،
وتتجاهل التطويل (ـ). فكل صيغة في العمود الواحد تُقرأ الكلمةَ نفسها:

| الكلمة | صيغ مقبولة أيضًا |
| --- | --- |
| `إذا` | `اذا` |
| `وإلا` | `والا` |
| `أرجع` | `ارجع` |
| `أو` | `او` |
| `خطأ` | `خطا` |
| `الأصل` | `الاصل` |
| `دالة` | `داله`، `دالـة` |
| `في` | `فى` |
| `أخيرًا` | `أخيرا`، `اخيرا` |
| `ارمِ` | `ارم` |

!!! note "التشكيل لا يُتجاهل"
    التسامح في الهمزات فقط، **لا في التشكيل**: `صنّف` بالشدّة اسم عادي لا الكلمة
    المفتاحية `صنف`، و`رشّح` اسم دالة مدمجة لا تلتبس بشيء. لو حُذف التشكيل
    لصارت أسماء كثيرة محجوزة بلا داعٍ. انظر [قرارات التصميم](../internals/design.md).
