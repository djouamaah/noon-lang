# توابع الأنواع

التوابع تُنادى بالنقطة على القيمة: `"نصّ".طول()`، `قائمة.أضف(٣)`. وأسماؤها
تقبل الكتابة بالهمزة أو بدونها (`أضف` و`اضف`).

## النصوص

النصوص لا تتغيّر: كل تابع يُرجع نصًّا جديدًا ويترك الأصل.

| التابع | يُرجع |
| --- | --- |
| `.طول()` | عدد الأحرف |
| `.قص([أحرف])` | النصّ بلا مسافات في طرفيه، أو بلا الأحرف المذكورة |
| `.تقسيم([فاصل])` | قائمة المقاطع؛ بلا فاصل يقسم على المسافات، وبفاصل فارغ `""` يقسم حرفًا حرفًا |
| `.استبدل(قديم، جديد)` | النصّ وقد استُبدل كل `قديم` بـ`جديد` |
| `.يحتوي(مقطع)` | هل المقطع فيه؟ |
| `.يبدأ(مقطع)` | هل يبدأ به؟ |
| `.ينتهي(مقطع)` | هل ينتهي به؟ |
| `.موضع(مقطع)` | فهرس أوّل ظهور، أو `-1` |
| `.مقطع(بداية، [نهاية])` | الأحرف من `بداية` إلى ما قبل `نهاية` |
| `.تكرار(عدد)` | النصّ مكرّرًا |
| `.عكس()` | النصّ معكوسًا |
| `.كبير()` | الأحرف اللاتينية كبيرة |
| `.صغير()` | الأحرف اللاتينية صغيرة |
| `.أحرف()` | قائمة الأحرف |

```noon
متغير س = "--صحيح البخاري--"
اطبع(س.قص("-")، س.طول()، س.موضع("البخاري"))
اطبع("أ،ب،ج".تقسيم("،")، "نون".أحرف())
اطبع("البخاري".مقطع(٢)، "البخاري".يبدأ("ال")، "Noon".صغير())
```

```output
صحيح البخاري 16 7
["أ"، "ب"، "ج"] ["ن"، "و"، "ن"]
بخاري صحيح noon
```

## القوائم

| التابع | يُرجع | يغيّر القائمة؟ |
| --- | --- | --- |
| `.طول()` | عدد العناصر | لا |
| `.أضف(قيمة، ...)` | القائمة نفسها بعد إضافة القيم إلى آخرها | **نعم** |
| `.إدراج(فهرس، قيمة)` | القائمة نفسها بعد الإدراج | **نعم** |
| `.احذف(فهرس)` | العنصر المحذوف | **نعم** |
| `.مسح()` | القائمة نفسها فارغة | **نعم** |
| `.يحتوي(قيمة)` | هل القيمة فيها؟ | لا |
| `.موضع(قيمة)` | فهرس أوّل ظهور، أو `-1` | لا |
| `.فرز([مفتاح]، [تنازلي])` | قائمة جديدة مرتّبة | لا |
| `.عكس()` | قائمة جديدة معكوسة | لا |
| `.وصل([فاصل])` | نصّ من العناصر بينها الفاصل | لا |
| `.مقطع(بداية، [نهاية])` | قائمة جديدة من جزء منها | لا |
| `.نسخة()` | نسخة سطحية | لا |
| `.ادمج(أخرى)` | قائمة جديدة فيها عناصر الاثنتين | لا |

```noon
متغير ق = [٣، ١]
ق.أضف(٤، ١، ٥)
اطبع(ق، ق.موضع(١)، ق.يحتوي(٩))
اطبع(ق.فرز()، ق.مقطع(١، ٣)، ق.وصل("-"))
اطبع(ق.احذف(٠)، ق)
```

```output
[3، 1، 4، 1، 5] 1 خطأ
[1، 1، 3، 4، 5] [1، 4] 3-1-4-1-5
3 [1، 4، 1، 5]
```

## القواميس

| التابع | يُرجع | يغيّر القاموس؟ |
| --- | --- | --- |
| `.طول()` | عدد المفاتيح | لا |
| `.مفاتيح()` | قائمة المفاتيح بترتيب إدخالها | لا |
| `.قيم()` | قائمة القيم | لا |
| `.عناصر()` | قائمة أزواج `[مفتاح، قيمة]` | لا |
| `.يحتوي(مفتاح)` | هل المفتاح موجود؟ | لا |
| `.اجلب(مفتاح، [افتراضي])` | القيمة، أو الافتراضي (`عدم`) إن غاب المفتاح | لا |
| `.ضع(مفتاح، قيمة)` | القاموس نفسه بعد الإسناد | **نعم** |
| `.احذف(مفتاح)` | القيمة المحذوفة | **نعم** |
| `.مسح()` | القاموس نفسه فارغًا | **نعم** |
| `.نسخة()` | نسخة سطحية | لا |

```noon
متغير م = {"أ": ١}
م.ضع("ب"، ٢).ضع("ج"، ٣)
اطبع(م.مفاتيح()، م.اجلب("د"، ٠))
اطبع(م.احذف("أ")، م.عناصر())
```

```output
["أ"، "ب"، "ج"] 0
1 [["ب"، 2]، ["ج"، 3]]
```
