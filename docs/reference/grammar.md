# الصيغة

## البنية المعجمية

| العنصر | القاعدة |
| --- | --- |
| **التعليق** | من `#` إلى آخر السطر |
| **نهاية الجملة** | سطر جديد، أو `؛`، أو `;` |
| **الفاصلة** | `،` أو `,` |
| **الاسم** | يبدأ بحرف أو `_`، ثم حروف وأرقام و`_` وتشكيل |
| **العدد** | أرقام لاتينية أو عربية-هندية أو فارسية؛ فاصلة عشرية `.` أو `٫`؛ فاصل آلاف `٬` أو `_` |
| **النصّ** | بين `"…"` أو `'…'` على سطر واحد، بتهريبات `\n` `\t` `\r` `\0` `\\` `\"` `\'` `\uXXXX` |

الأسطر الجديدة داخل `( )` و`[ ]` لا تُنهي الجملة، فالتعبير الطويل يُكسر داخل
الأقواس. وداخل `{ }` القاموس كذلك.

```noon
متغير المجموع = (١ + ٢ + ٣
                + ٤ + ٥)
متغير الأيام = [
    "السبت"،
    "الأحد"،
]
اطبع(المجموع، طول(الأيام))
```

```output
15 2
```

## قواعد الصيغة (EBNF)

```ebnf
برنامج       = { جملة } ;

جملة         = تصريح | إسناد | شرط | طالما | لكل | تعريف_دالة | تعريف_صنف
             | "أرجع" [ تعبير ] | "توقف" | "استمر" | "ارمِ" تعبير
             | حاول | كتلة | تعبير ;

تصريح        = ( "متغير" اسم [ "=" تعبير ] | "ثابت" اسم "=" تعبير ) ;
إسناد        = هدف ( "=" | "+=" | "-=" | "*=" | "/=" ) تعبير ;
هدف          = اسم | لاحقة "[" تعبير "]" | لاحقة "." اسم ;

شرط          = "إذا" تعبير كتلة [ "وإلا" ( شرط | كتلة ) ] ;
طالما        = "طالما" تعبير كتلة ;
لكل          = "لكل" [ "(" ] اسم "في" تعبير [ ")" ] كتلة ;
حاول         = "حاول" كتلة [ "امسك" [ "(" اسم ")" | اسم ] كتلة ]
               [ "أخيرًا" كتلة ] ;                (* واحدة منهما على الأقل *)

تعريف_دالة   = "دالة" اسم وسائط كتلة ;
وسائط        = "(" [ وسيط { "،" وسيط } ] ")" ;
وسيط         = اسم [ "=" تعبير ] ;
تعريف_صنف    = "صنف" اسم [ "يرث" اسم ] "{" { [ "دالة" ] اسم وسائط كتلة } "}" ;

كتلة         = "{" { جملة } "}" ;

تعبير        = أو ;
أو           = و { "أو" و } ;
و            = مساواة { "و" مساواة } ;
مساواة       = مقارنة { ( "==" | "!=" ) مقارنة } ;
مقارنة       = جمع { ( "<" | ">" | "<=" | ">=" | "في" ) جمع } ;
جمع          = ضرب { ( "+" | "-" ) ضرب } ;
ضرب          = أحادي { ( "*" | "/" | "//" | "%" ) أحادي } ;
أحادي        = ( "ليس" | "-" | "+" ) أحادي | أس ;
أس           = لاحقة [ "**" أحادي ] ;
لاحقة        = أوّلي { "(" [ تعبير { "،" تعبير } ] ")"
                     | "[" تعبير "]"
                     | "[" [ تعبير ] ":" [ تعبير ] "]"
                     | "." اسم } ;
أوّلي         = عدد | نص | "صحيح" | "خطأ" | "عدم" | اسم | "هذا" | "الأصل"
             | "(" تعبير ")" | قائمة | قاموس | دالة_مجهولة ;
قائمة        = "[" [ تعبير { "،" تعبير } [ "،" ] ] "]" ;
قاموس        = "{" [ تعبير ":" تعبير { "،" تعبير ":" تعبير } [ "،" ] ] "}" ;
دالة_مجهولة  = "دالة" [ اسم ] وسائط كتلة ;
```

## ملاحظات على الصيغة

**`{` في أوّل الجملة.** تُقرأ كتلةً، إلا إن تبعها «مفتاح:» فتُقرأ قاموسًا. لذلك
`{"أ": ١}.مفاتيح()` في أوّل سطر تعمل كما تتوقّع.

**`وإلا` بعد سطر جديد.** يجوز أن تبدأ `وإلا` سطرًا جديدًا بعد `}`.

**`دالة` في أوّل الجملة.** إن تبعها اسم فهي تعريف دالة، وإلا فهي تعبير يصنع
دالة مجهولة.

**الإسناد جملة لا تعبير.** `اطبع(س = ٣)` خطأ نحوي، وكذلك `أ = ب = ٠`.
