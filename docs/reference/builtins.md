# الدوال المدمجة

متاحة في كل مكان دون استيراد، وهي ثوابت لا يُسند إليها. ما كان بين قوسين معقوفين
`[ ]` في التوقيع فهو اختياري.

!!! tip "الهمزة والشدّة اختياريتان في أسمائها"
    `أقصى` تُكتب `اقصى` أيضًا، و`طبّق` تُكتب `طبق`، و`رشّح` تُكتب `رشح`.

## الإدخال والإخراج

| الدالة | عملها |
| --- | --- |
| `اطبع(...)` | تطبع وسائطها مفصولة بمسافة ثم سطرًا جديدًا. بلا وسائط تطبع سطرًا فارغًا. |
| `اقرأ([رسالة])` | تعرض الرسالة وتقرأ سطرًا من المستخدم، وتُرجعه نصًّا. |
| `استورد(اسم)` | تُحمِّل وحدة (ملف «نون» أو وحدة من [المكتبة القياسية](../library/index.md)) وتُرجعها؛ انظر [الوحدات](../guide/modules.md). |
| `اقرأ_ملف(مسار)` | محتوى ملف نصّي بترميز UTF-8. |
| `وسائط()` | قائمة الوسائط المكتوبة بعد اسم البرنامج: `noon برنامج.noon أ ب` تُعطي `["أ"، "ب"]`. |
| `احفظ_مترجما(مسار، بنية)` | تكتب ملف `.noonc` من بنية دالة مُترجَمة، وتُرجع حجمه بالبايت. يستعملها [المترجِم المكتوب بـ«نون»](../internals/compiler.md). |

```noon
اطبع("س =", ٤، [١، ٢]، عدم، صحيح)
```

```output
س = 4 [1، 2] عدم صحيح
```

## الأنواع والتحويل

| الدالة | عملها |
| --- | --- |
| `نوع(س)` | اسم نوع القيمة: `عدد`، `نص`، `منطقي`، `عدم`، `قائمة`، `قاموس`، `دالة`، `صنف`، أو اسم صنف الكائن |
| `نص(س)` | القيمة نصًّا كما تُطبع |
| `عدد(س)` | نصّ أو منطقي إلى عدد؛ تفهم الأرقام العربية و`٫` |
| `منطقي(س)` | `صحيح` أو `خطأ` بحسب [قاعدة الصدق](../guide/values.md#القيم-المنطقية-والشروط) |
| `قائمة(س)` | قائمة من عناصر قائمة أو أحرف نصّ أو مفاتيح قاموس |
| `طول(س)` | عدد عناصر قائمة أو أحرف نصّ أو مفاتيح قاموس |
| `من_صنف(كائن، صنف)` | هل الكائن من هذا الصنف أو من صنف يرثه؟ |
| `متساويان(أ، ب)` | مثل `أ == ب` |

```noon
اطبع(عدد("٤٢") + ١، نص(٣٫٥) + "!"، قائمة("نون")، طول({"أ": ١}))
```

```output
43 3.5! ["ن"، "و"، "ن"] 1
```

## الأعداد

| الدالة | عملها |
| --- | --- |
| `مدى(نهاية)` | قائمة من ٠ إلى `نهاية - 1` |
| `مدى(بداية، نهاية، [خطوة])` | من `بداية` إلى ما قبل `نهاية` |
| `مجموع(قائمة)` | مجموع أعداد القائمة |
| `أقصى(قائمة)` أو `أقصى(أ، ب، ...)` | أكبر قيمة (أعداد أو نصوص) |
| `أدنى(قائمة)` أو `أدنى(أ، ب، ...)` | أصغر قيمة |
| `مطلق(س)` | القيمة المطلقة |
| `جذر(س)` | الجذر التربيعي |
| `تقريب(س، [منازل])` | تقريب إلى عدد من المنازل العشرية (الافتراض صفر) |
| `أرضية(س)` | أكبر صحيح لا يتجاوز `س` |
| `سقف(س)` | أصغر صحيح لا يقلّ عن `س` |
| `عشوائي()` | عدد عشري عشوائي في [٠، ١) |
| `عشوائي(حد)` | عدد صحيح عشوائي من ٠ إلى `حد - 1` |
| `عشوائي(من، إلى)` | عدد صحيح عشوائي من `من` إلى `إلى` شاملًا |
| `وقت()` | الثواني منذ ١ يناير ١٩٧٠، لقياس المدد |
| `باي` | ثابت π ‏(3.141592653589793) |

```noon
اطبع(مجموع(مدى(١، ١٠١))، أقصى(٣، ٩، ٤)، أدنى(["ب"، "أ"]))
اطبع(جذر(٢)، تقريب(جذر(٢)، ٣)، أرضية(-٢٫٥)، سقف(-٢٫٥))
```

```output
5050 9 أ
1.4142135623730951 1.414 -3 -2
```

!!! note "التقريب إلى الزوجي"
    `تقريب` تقرّب النصف إلى أقرب عدد زوجي: `تقريب(٢٫٥)` هي `2` و`تقريب(٣٫٥)`
    هي `4`. هذا يمنع انحياز المجاميع إلى الأعلى عند تقريب قيم كثيرة.

## القوائم والدوال

| الدالة | عملها |
| --- | --- |
| `فرز(قائمة، [مفتاح]، [تنازلي])` | قائمة جديدة مرتّبة؛ `مفتاح` دالة تُرتَّب بنتيجتها |
| `عكس(س)` | قائمة أو نصّ معكوس |
| `طبّق(دالة، قائمة)` | قائمة بنتيجة الدالة على كل عنصر |
| `رشّح(دالة، قائمة)` | العناصر التي تُرجع لها الدالة قيمة صادقة |
| `اختزل(دالة، قائمة، [بداية])` | تطوي القائمة: `دالة(المتراكم، العنصر)` |

```noon
متغير ق = [٥، ٣، ٨، ١]
اطبع(فرز(ق)، فرز(ق، عدم، صحيح)، عكس("سلام"))
اطبع(اختزل(دالة(أ، ب) { أرجع أ * ب }، ق))
```

```output
[1، 3، 5، 8] [8، 5، 3، 1] مالس
120
```

## أخرى

| الدالة | عملها |
| --- | --- |
| `تحقّق(شرط، [رسالة])` | ترمي خطأ تشغيل إن كان الشرط كاذبًا |
| `أرقام_عربية([مفعّل])` | تجعل الأعداد تُطبع بالأرقام العربية-الهندية (أو تعيدها لاتينية بـ`خطأ`) |
| `رمز(حرف)` | رقم الحرف في يونيكود |
| `محرف(رقم)` | الحرف الذي رقمه في يونيكود هو `رقم`؛ عكس `رمز` |
| `عضو(كائن، اسم)` | مثل `كائن.اسم` والاسم نصّ يُعرف وقت التشغيل |

```noon
اطبع(رمز("ن")، محرف(١٦٠٦)، عضو([١، ٢، ٣]، "طول")())
```

```output
1606 ن 3
```

```noon
اطبع(١٢٣٤٫٥)
أرقام_عربية()
اطبع(١٢٣٤٫٥)
```

```output
1234.5
١٢٣٤٫٥
```
