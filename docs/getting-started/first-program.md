# أوّل برنامج

نكتب برنامجًا صغيرًا يحسب درجات طلّاب ويصنّفهم، ونمرّ في الطريق على أهمّ
ما في اللغة.

## البرنامج كاملًا

```noon
# درجات الطلّاب: قاموس من الاسم إلى قائمة الدرجات
ثابت الدرجات = {
    "أمينة": [١٨، ١٦، ١٩]،
    "يوسف": [١٢، ٩، ١٤]،
    "مريم": [٨، ١١، ٧]،
}

دالة المعدّل(قائمة_) {
    أرجع مجموع(قائمة_) / طول(قائمة_)
}

دالة التقدير(معدّل) {
    إذا (معدّل >= ١٦) { أرجع "ممتاز" }
    وإلا إذا (معدّل >= ١٠) { أرجع "ناجح" }
    وإلا { أرجع "راسب" }
}

لكل اسم في الدرجات {
    متغير م = المعدّل(الدرجات[اسم])
    اطبع(اسم + ":", تقريب(م، ٢)، "—", التقدير(م))
}
```

```output
أمينة: 17.67 — ممتاز
يوسف: 11.67 — ناجح
مريم: 8.67 — راسب
```

## ماذا حدث؟

**التعليقات** تبدأ بـ`#` وتمتدّ إلى آخر السطر.

**`ثابت`** يعرّف اسمًا لا تتغيّر قيمته. لو كتبنا بعدها `الدرجات = {}` لتوقّف
البرنامج بخطأ. للقيم التي تتغيّر استعمل [`متغير`](../guide/variables.md).

**القاموس** `{ مفتاح: قيمة }` يربط كل اسم بقائمة، والفاصلة العربية `،` واللاتينية
`,` سواء، والفاصلة الزائدة بعد آخر عنصر مسموحة.

**`دالة`** تعرّف دالة، و`أرجع` تُعيد قيمتها. الأقواس حول الشرط في `إذا`
اختيارية، أما القوسان المعقوفان `{ }` فإلزاميان.

**`لكل … في`** تمرّ على مفاتيح القاموس بترتيب إدخالها.

**`اطبع`** تطبع وسائطها مفصولة بمسافة، و`تقريب(م، ٢)` تقرّب إلى منزلتين.

!!! note "الأرقام"
    كتبنا الدرجات بالأرقام العربية-الهندية، وطُبعت النتائج باللاتينية لأنها
    الافتراض. شغّل البرنامج بـ`python noon.py --عربي` لتُطبع `١٧٫٦٧`.

## جرّب أن تخطئ

غيّر `المعدّل(الدرجات[اسم])` إلى `المعدل(الدرجات[اسم])` — بلا شدّة — وشغّل:

```noon
دالة المعدّل(ق) { أرجع مجموع(ق) / طول(ق) }
اطبع(المعدل([١، ٢]))
```

```output
خطأ تشغيل [سطر 2]: المتغيّر «المعدل» غير مُعرَّف
```

الأسماء في «نون» تُطابَق حرفًا بحرف، بتشكيلها. الكلمات المفتاحية وحدها تتسامح
في الهمزات (`إذا` و`اذا` سواء) — انظر [الكلمات المفتاحية](../reference/keywords.md).
