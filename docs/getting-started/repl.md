# الصدفة التفاعلية

شغّل المُفسِّر بلا وسائط لتفتح صدفة (REPL) تكتب فيها سطرًا فيُنفَّذ فورًا:

```bash
python noon.py
```

```text
  ن و ن — لغة برمجة عربية · الإصدار ١٫٠
  اكتب شيفرتك ثم Enter. «مساعدة» للتعليمات، «خروج» للخروج.
نون> متغير س = ٤
نون> س * ٣
12
نون> "نصّ"
"نصّ"
```

## قيمة التعبير تُعرض وحدها

إن كان السطر تعبيرًا — لا تصريحًا ولا إسنادًا — طُبعت قيمته، والنصوص تُعرض بين
علامتي اقتباس حتى تميّز `"12"` من `12`. أما `اطبع` فتطبع النصّ كما هو.

## أسطر متعدّدة

إذا فتحت قوسًا ولم تغلقه تنتظر الصدفة بقيّة الكتلة، ويتغيّر المِحَثّ إلى `...`:

```text
نون> دالة مربّع(ع) {
  ...     أرجع ع * ع
  ... }
نون> مربّع(٧)
49
```

## ما تعرّفه يبقى

كل ما تعرّفه في سطر يبقى متاحًا في الأسطر التالية حتى تخرج. والأخطاء لا تُنهي
الصدفة: يُعرض الخطأ مع موضعه وتتابع.

```text
نون> اطبع(ص)
خطأ تشغيل [سطر 1]: المتغيّر «ص» غير مُعرَّف
  اطبع(ص)
```

## أوامر الصدفة

| الأمر | عمله |
| --- | --- |
| `مساعدة` أو `؟` | عرض التعليمات وأمثلة سريعة |
| `مسح` | مسح الشاشة |
| `خروج` أو ++ctrl+d++ | إنهاء الصدفة |
| ++ctrl+c++ | إيقاف برنامج طال تنفيذه دون الخروج |
