# القوائم والقواميس

## القوائم

القائمة سلسلة مرتّبة من أي قيم، بين قوسين مربّعين:

```noon
متغير ق = [١٠، "نصّ"، صحيح، [١، ٢]]
اطبع(ق[٠]، ق[-١]، ق[٣][٠]، طول(ق))
```

```output
10 [1، 2] 1 4
```

الفهرسة والتقطيع كما في [النصوص](strings.md#الفهرسة-والتقطيع)، والإسناد بالفهرس
يغيّر العنصر:

```noon
متغير الأيام = ["سبت"، "أحد"، "اثنين"]
الأيام[١] = "الأحد"
اطبع(الأيام، الأيام[١:])
```

```output
["سبت"، "الأحد"، "اثنين"] ["الأحد"، "اثنين"]
```

### تعديل القائمة

`أضف` و`احذف` و`إدراج` و`مسح` تغيّر القائمة نفسها:

```noon
متغير ق = [١، ٢]
ق.أضف(٣)
ق.أضف(٤، ٥)
ق.إدراج(٠، ٠)
متغير المحذوف = ق.احذف(-١)
اطبع(ق، "حُذف:", المحذوف)
```

```output
[0، 1، 2، 3، 4] حُذف: 5
```

### توابع تُرجع قائمة جديدة

`فرز` و`عكس` و`نسخة` و`ادمج` و`مقطع` لا تغيّر الأصل:

```noon
متغير الأصلية = [٣، ١، ٢]
متغير المفروزة = الأصلية.فرز()
اطبع(الأصلية، المفروزة، الأصلية.فرز(عدم، صحيح))
```

```output
[3، 1، 2] [1، 2، 3] [3، 2، 1]
```

!!! warning "القوائم تُشارَك لا تُنسخ"
    `متغير ب = أ` يجعل الاسمين يشيران إلى القائمة **نفسها**؛ تعديل إحداهما يظهر
    في الأخرى. استعمل `أ.نسخة()` حين تريد نسخة مستقلّة.

```noon
متغير أ = [١]
متغير ب = أ
متغير ج = أ.نسخة()
ب.أضف(٢)
اطبع(أ، ج)
```

```output
[1، 2] [1]
```

## القواميس

القاموس يربط مفاتيح بقيم. المفاتيح نصوص أو أعداد، ويُحفظ ترتيب إدخالها:

```noon
متغير كتاب = {
    "العنوان": "صحيح البخاري"،
    "الأجزاء": ٩،
}

اطبع(كتاب["العنوان"])
كتاب["المؤلّف"] = "البخاري"
كتاب["الأجزاء"] += ١
اطبع(كتاب)
```

```output
صحيح البخاري
{"العنوان": "صحيح البخاري"، "الأجزاء": 10، "المؤلّف": "البخاري"}
```

المفتاح الغائب خطأ عند القراءة بالقوسين، أما `اجلب` فتُرجع قيمة افتراضية:

```noon
متغير م = {"أ": ١}
اطبع(م.اجلب("ب")، م.اجلب("ب"، ٠)، "ب" في م)
اطبع(م["ب"])
```

```output
عدم 0 خطأ
خطأ تشغيل [سطر 3]: المفتاح «ب» غير موجود في القاموس
```

ويجوز الوصول بالنقطة إلى مفتاح نصّي ما لم يكن اسمه اسمَ تابع:

```noon
متغير نقطة = {"س": ٣، "ص": ٤}
نقطة.س = ٦
اطبع(نقطة.س، نقطة["س"])
```

```output
6 6
```

### المرور على القاموس

```noon
متغير الدرجات = {"أمينة": ١٨، "يوسف": ١٢}
اطبع(الدرجات.مفاتيح())
اطبع(الدرجات.قيم())
اطبع(الدرجات.عناصر())
```

```output
["أمينة"، "يوسف"]
[18، 12]
[["أمينة"، 18]، ["يوسف"، 12]]
```

### مثال: عدّ التكرار

```noon
متغير النصّ = "من جدّ وجد ومن زرع حصد ومن سار على الدرب وصل"
متغير العدد = {}
لكل كلمة في النصّ.تقسيم(" ") {
    العدد.ضع(كلمة، العدد.اجلب(كلمة، ٠) + ١)
}
متغير الأكثر = فرز(العدد.مفاتيح()، دالة(ك) { أرجع العدد[ك] }، صحيح)[٠]
اطبع("أكثر الكلمات تكرارًا:", الأكثر، "—", العدد[الأكثر]، "مرّات")
```

```output
أكثر الكلمات تكرارًا: ومن — 2 مرّات
```

!!! note "الواو ملتصقة"
    «من» في النصّ ثلاث مرّات، لكن اثنتين منها «ومن»: واو العطف جزء من الكلمة
    المكتوبة، فالتقسيم على المسافات يعدّهما كلمتين مختلفتين. تحليل النصّ العربي
    الجادّ يحتاج إلى فصل السوابق قبل العدّ.
