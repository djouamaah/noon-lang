# النصوص

## الكتابة

النصّ بين علامتي اقتباس مزدوجتين أو مفردتين، ولا يمتدّ على أكثر من سطر:

```noon
اطبع("نصّ بعلامتين مزدوجتين"، 'ونصّ بمفردتين')
```

```output
نصّ بعلامتين مزدوجتين ونصّ بمفردتين
```

### التهريب

| الكتابة | معناها |
| --- | --- |
| `\n` | سطر جديد |
| `\t` | مسافة جدولة |
| `\"` و`\'` | علامة اقتباس |
| `\\` | شرطة مائلة |
| `\u0646` | المحرف بترميزه (هنا «ن») |

وما سوى ذلك يبقى كما كُتب، فمسارات ويندوز لا تحتاج إلى مضاعفة الشرطة:

```noon
اطبع("سطر أول\nسطر ثانٍ")
اطبع("C:\Users\noon")
اطبع("\u0646\u0648\u0646")
```

```output
سطر أول
سطر ثانٍ
C:\Users
oon
نون
```

!!! warning "انتبه لـ`\n` داخل المسارات"
    في المثال السابق صارت `\noon` سطرًا جديدًا ثم `oon`، لأن `\n` تهريب معروف.
    اكتب `\\noon` حين تقصد الشرطة نفسها.

## الفهرسة والتقطيع

الفهرس يبدأ من صفر، والسالب يعدّ من النهاية، و`[من:إلى]` يقطع مقطعًا:

```noon
متغير كلمة = "البخاري"
اطبع(كلمة[٠]، كلمة[-١]، كلمة[٢:٥]، كلمة[:٢]، كلمة[٢:])
اطبع(طول(كلمة))
```

```output
ا ي بخا ال بخاري
7
```

الفهرس خارج الحدود خطأ، أما التقطيع فيتسامح:

```noon
اطبع("نون"[:١٠])
اطبع("نون"[٥])
```

```output
نون
خطأ تشغيل [سطر 2]: الفهرس 5 خارج الحدود (الطول 3)
```

## التوابع

```noon
متغير جملة = "  العلم نور والجهل ظلام  "

اطبع("[" + جملة.قص() + "]")
اطبع(جملة.قص().تقسيم(" "))
اطبع(جملة.استبدل("ظلام"، "عتمة").قص())
اطبع(جملة.يحتوي("نور")، جملة.قص().يبدأ("العلم")، جملة.موضع("نور"))
اطبع("ها".تكرار(٣)، "نون".عكس()، "Noon".كبير())
```

```output
[العلم نور والجهل ظلام]
["العلم"، "نور"، "والجهل"، "ظلام"]
العلم نور والجهل عتمة
صحيح صحيح 8
هاهاها نون NOON
```

القائمة الكاملة في [توابع الأنواع](../reference/methods.md#النصوص).

## تركيب النصوص

`+` تصل نصًّا بأي قيمة، و`نص()` تحوّل صراحةً، و`وصل` تجمع قائمة بفاصل:

```noon
متغير الاسم = "هند"
متغير العمر = ٢٥
اطبع(الاسم + " عمرها " + العمر)
اطبع(["أ"، "ب"، "ج"].وصل(" ← "))
```

```output
هند عمرها 25
أ ← ب ← ج
```
