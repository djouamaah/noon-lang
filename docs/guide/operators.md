# العمليات

## الحسابية

| العملية | معناها | مثال | النتيجة |
| --- | --- | --- | --- |
| `+` | جمع | `٧ + ٢` | `9` |
| `-` | طرح | `٧ - ٢` | `5` |
| `*` | ضرب | `٧ * ٢` | `14` |
| `/` | قسمة | `٧ / ٢` | `3.5` |
| `//` | قسمة صحيحة | `٧ // ٢` | `3` |
| `%` | باقي القسمة | `٧ % ٢` | `1` |
| `**` | أُسّ | `٧ ** ٢` | `49` |

القسمة بين عددين صحيحين تبقى صحيحة إن كانت مضبوطة، والقسمة على صفر خطأ:

```noon
اطبع(٦ / ٣، ٧ / ٢)
اطبع(١ / ٠)
```

```output
2 3.5
خطأ تشغيل [سطر 2]: القسمة على صفر
```

## مع النصوص والقوائم

`+` تصل النصوص والقوائم وتدمج القواميس، و`*` تكرّر النصّ أو القائمة.
وجمع نصّ مع أي قيمة أخرى يحوّل تلك القيمة نصًّا:

```noon
اطبع("نون" + "!"، "ـ" * ٥)
اطبع([١، ٢] + [٣]، [٠] * ٣)
اطبع({"أ": ١} + {"ب": ٢})
اطبع("عمري " + ٣٠ + " سنة")
```

```output
نون! ـــــ
[1، 2، 3] [0، 0، 0]
{"أ": 1، "ب": 2}
عمري 30 سنة
```

وما لا معنى له خطأ صريح:

```noon
اطبع([١] + ١)
```

```output
خطأ تشغيل [سطر 1]: لا يمكن جمع «قائمة» مع «عدد»
```

## المقارنة

`==` و`!=` تقارنان أي قيمتين، و`<` و`>` و`<=` و`>=` تقارن عددين أو نصّين.

**المساواة صارمة**: القيم من نوعين مختلفين لا تتساوى أبدًا، فالمنطقي ليس عددًا.
والقوائم والقواميس تتساوى إن تساوت عناصرها:

```noon
اطبع(١ == صحيح، ٠ == خطأ، "١" == ١)
اطبع([١، [٢]] == [١، [٢]]، {"أ": ١} == {"أ": ١})
اطبع("باء" < "تاء"، ١٠ > ٩)
```

```output
خطأ خطأ خطأ
صحيح صحيح
صحيح صحيح
```

ومقارنة الترتيب بين نوعين مختلفين خطأ لا نتيجة اعتباطية:

```noon
اطبع(١ < "٢")
```

```output
خطأ تشغيل [سطر 1]: لا يمكن المقارنة بين «عدد» و«نص»
```

## `في`

`في` تسأل عن الانتماء: حرف أو مقطع في نصّ، عنصر في قائمة، مفتاح في قاموس:

```noon
اطبع("خار" في "البخاري"، ٣ في [١، ٢، ٣]، "س" في {"س": ٠})
```

```output
صحيح صحيح صحيح
```

## المنطقية

| العملية | بديلها | معناها |
| --- | --- | --- |
| `و` | `&&` | صادقة إن صدق الطرفان |
| `أو` | `\|\|` | صادقة إن صدق أحدهما |
| `ليس` | `!` | عكس الصدق |

`و` و`أو` **تختصران**: لا يُحسب الطرف الثاني إن حُسم الأمر بالأول. وتُرجعان
أحد الطرفين نفسه لا `صحيح`/`خطأ`، فتصلح `أو` لقيمة افتراضية:

```noon
متغير الاسم = ""
اطبع(الاسم أو "مجهول")
اطبع(عدم و اطبع("لن يُطبع"))
اطبع(ليس ٠، !صحيح)
```

```output
مجهول
عدم
صحيح خطأ
```

!!! warning "افصل `و` بمسافتين"
    `و` كلمة مستقلّة: `س و ص`. أما `وص` فاسم واحد يبدأ بالواو.

## الإسناد المركّب

`+=` و`-=` و`*=` و`/=` اختصار لـ`س = س + …`، وتعمل مع الفهارس والأعضاء أيضًا:

```noon
متغير ق = [١٠، ٢٠]
ق[٠] += ٥
متغير م = {"عدد": ١}
م["عدد"] *= ٤
اطبع(ق، م)
```

```output
[15، 20] {"عدد": 4}
```

## الأسبقية

من الأضعف إلى الأقوى. ما تساوت أسبقيته يُحسب بترتيب كتابته، عدا `**`:

| الأسبقية | العمليات |
| --- | --- |
| ١ | `أو` |
| ٢ | `و` |
| ٣ | `==` `!=` |
| ٤ | `<` `>` `<=` `>=` `في` |
| ٥ | `+` `-` |
| ٦ | `*` `/` `//` `%` |
| ٧ | `ليس` و`-` الأحادية |
| ٨ | `**` (تُجمَّع من آخرها: `٢ ** ٣ ** ٢` هي `٢ ** ٩`) |
| ٩ | الاستدعاء `()` والفهرسة `[]` والعضو `.` |

```noon
اطبع(٢ + ٣ * ٤، (٢ + ٣) * ٤، ٢ ** ٣ ** ٢، -٢ ** ٢)
```

```output
14 20 512 -4
```
