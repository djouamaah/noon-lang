# الوحدات

البرنامج الكبير يُقسَّم ملفّات، وما يتكرّر بين البرامج يُكتب مرّة في **وحدة**
تُستورد حيث تلزم. والوحدة ملف «نون» عادي؛ و`استورد` تُنفّذه وتُرجع ما عرّفه.

## الاستيراد

```noon
متغير ر = استورد("رياضيات")
اطبع(ر.عاملي(١٠))
اطبع(ر.الأعداد_الأولية(٢٠))
```

```output
3628800
[2، 3، 5، 7، 11، 13، 17، 19]
```

`استورد` دالة لا كلمة مفتاحية: تأخذ اسم الوحدة نصًّا وتُرجع قيمة من نوع `وحدة`،
تُقرأ منها تعريفاتها بالنقطة. والاسم الذي تحفظها فيه اختيارك:

```noon
متغير رياضيات = استورد("رياضيات")
اطبع(نوع(رياضيات)، رياضيات)
اطبع(رياضيات.قاسم_مشترك(٨٤، ٣٦))
```

```output
وحدة <وحدة رياضيات>
12
```

`رياضيات` من [المكتبة القياسية](../library/index.md): وحدات تأتي مع اللغة،
مكتوبة بـ«نون» نفسها.

## وحدتك أنت

أي ملف `.noon` وحدة. اكتب `هندسة.noon` بجوار برنامجك:

```text
# هندسة.noon
ثابت نصف_دورة = باي

دالة مساحة_دائرة(نق) { أرجع نصف_دورة * نق ** ٢ }

دالة _مربع(س) { أرجع س * س }        # «_» في أوّل الاسم: داخلي

دالة وتر(أ، ب) { أرجع جذر(_مربع(أ) + _مربع(ب)) }
```

ثم استوردها باسمها بلا امتداد:

```text
متغير ش = استورد("هندسة")
اطبع(ش.وتر(٣، ٤))          # 5
اطبع(ش._مربع(٣))           # خطأ: الوحدة «هندسة» لا تحوي «_مربع»
```

- **ما يُصدَّر:** كل ما عُرِّف في المستوى الأعلى للوحدة من متغيّرات وثوابت ودوال
  وأصناف، إلا ما بدأ اسمه بـ`_`.
- **عوامّ الوحدة لها:** دوال الوحدة ترى متغيّرات وحدتها لا متغيّرات البرنامج
  الذي يناديها، وإن تشابهت الأسماء. وما تغيّره منها يُرى من الخارج:
  إن زادت دالةٌ عدّادًا في وحدتها فقراءته بعدها تُعطي قيمته الجديدة.
- **تُنفَّذ مرّة واحدة:** الاستيراد الثاني للوحدة نفسها يُرجع القيمة نفسها دون
  تنفيذ ملفها ثانيةً، فتُشارك حالتها بين كل من استوردها.

## أين يُبحث عن الوحدة

1. في مجلّد الملف الذي يستورد: مجلّد البرنامج، أو مجلّد الوحدة إن استوردت هي
   غيرها. من الصدفة أو `-c`: المجلّد الحالي.
2. ثم في المكتبة القياسية.

فملفّك `رياضيات.noon` بجوار البرنامج يُقدَّم على وحدة المكتبة بالاسم نفسه.
ويُقبل الامتدادان `.noon` و`.نون`، والمسار النسبي بمجلّداته:
`استورد("أدوات/نصوص")` يبحث عن `أدوات/نصوص.noon` في مجلّد المستورِد فقط.

## الأخطاء

خطأ يقع داخل دالة من وحدة يذكر الوحدة وسطره فيها؛ ويعرض سطر الأوامر بعده سطر
برنامجك الذي بدأ منه النداء، فتعرف أيّ نداء أوصل إليه:

```text
خطأ تشغيل [سطر 20 في «رياضيات»]: «عاملي» تحتاج عددًا صحيحًا غير سالب، لا -1 (حساب.noon)
  تحقّق(_صحيح(ن) و ن >= ٠، "«" + دالة_ + "» تحتاج عددًا صحيحًا غير سالب، لا " + نص(ن))
  استُدعيت من السطر 7 في البرنامج:
  اطبع(ر.عاملي(ع - ٨))
```

وفي [ساحة التجربة](../playground/index.html) يُعلَّم سطر برنامجك هذا. أمّا دالة من
برنامجك تمرّرها إلى الوحدة فتناديها، فخطؤها خطأ برنامجك وبسطره هو.

وخطأ داخل ملف الوحدة وهي تُحمَّل يُبلَّغ في سطر `استورد`، ويذكر اسم الوحدة وسطره
فيها:

```text
خطأ تشغيل [سطر 1]: خطأ نحوي في الوحدة «هندسة» [سطر 3]: تعبير غير متوقّع: «)»
```

ووحدتان تستورد كلّ منهما الأخرى خطأ، لأن كلتيهما تنتظر أن تكتمل الأخرى أوّلًا:

```text
خطأ تشغيل [سطر 1]: استيراد دائري: أ ← ب ← أ
```

والخطأ لا يُحمّل الوحدة، فيمكن التقاطه:

```noon
حاول {
    استورد("وحدة_غير_موجودة")
} امسك (خ) {
    اطبع(خ["رسالة"])
}
```

```output
لا توجد وحدة باسم «وحدة_غير_موجودة»
```
