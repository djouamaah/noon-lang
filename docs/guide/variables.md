# المتغيّرات والنطاقات

## التصريح والإسناد

`متغير` يصرّح باسم جديد، والإسناد بـ`=` يغيّر قيمة اسم موجود:

```noon
متغير العدّ = ١٠
العدّ = العدّ + ٥
العدّ += ١
اطبع(العدّ)
```

```output
16
```

**التصريح إلزامي.** الإسناد إلى اسم لم يُصرَّح به خطأ، حتى لا يصنع خطأٌ إملائي
متغيّرًا جديدًا في صمت:

```noon
متغير المجموع = ٠
المجموغ = ٥
```

```output
خطأ تشغيل [سطر 2]: المتغيّر «المجموغ» غير مُعرَّف؛ استعمل «متغير المجموغ = ...» أوّلًا
```

والتصريح بلا قيمة يعطي `عدم`. ولا يُصرَّح بالاسم نفسه مرّتين في النطاق نفسه:

```noon
متغير س = ١
متغير س = ٢
```

```output
خطأ تشغيل [سطر 2]: «س» مُعرَّف مسبقًا في هذا النطاق
```

## الثوابت

`ثابت` يصرّح باسم لا تتغيّر قيمته، ولا بدّ أن تُسند إليه قيمة:

```noon
ثابت الحدّ_الأقصى = ١٠٠
الحدّ_الأقصى = ٢٠٠
```

```output
خطأ تشغيل [سطر 2]: «الحدّ_الأقصى» ثابت، لا يمكن تغيير قيمته
```

!!! note "الثابت يحمي الاسم لا القيمة"
    `ثابت ق = [١]` يمنع `ق = [٢]`، لكنه لا يمنع `ق.أضف(٢)`: القائمة نفسها
    قابلة للتعديل.

والدوال المدمجة ثوابت كذلك: `اطبع = ٥` خطأ.

## الأسماء

الاسم يبدأ بحرف أو شرطة سفلية `_`، ويتبعه حروف أو أرقام أو `_` أو تشكيل:
`س`، `العدد_الكلّي`، `مربّع٢`، `_مؤقت`، `total`.

- **التشكيل جزء من الاسم**: `مربّع` و`مربع` اسمان مختلفان.
- **الكلمات المفتاحية محجوزة**: لا يُسمّى متغيّر `إذا` أو `صنف` — انظر
  [قائمتها](../reference/keywords.md).
- الأسماء بالعربية واللاتينية سواء، لكن الاتّساق أيسر للقارئ.

## النطاقات

كل كتلة `{ … }` نطاق: ما يُصرَّح به داخلها لا يُرى خارجها، ويحجب ما يحمل اسمه
في الخارج دون أن يغيّره:

```noon
متغير س = "خارجي"
{
    متغير س = "داخلي"
    اطبع(س)
}
اطبع(س)
```

```output
داخلي
خارجي
```

أما الإسناد بلا `متغير` فيغيّر أقرب متغيّر بهذا الاسم في النطاقات المحيطة:

```noon
متغير المجموع = ٠
لكل ن في [١، ٢، ٣] {
    المجموع += ن
}
اطبع(المجموع)
```

```output
6
```

والدوال تتذكّر نطاق تعريفها — انظر [الإغلاق](functions.md#الإغلاق-closures).
