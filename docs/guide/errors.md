# الأخطاء

## نوعان من الأخطاء

**الخطأ النحوي** يُكتشف قبل أن يبدأ التشغيل، فلا يُنفَّذ من البرنامج شيء:

```noon
اطبع("قبل")
اطبع(١ + )
```

```output
خطأ نحوي [سطر 2]: تعبير غير متوقّع: «)»
```

**خطأ التشغيل** يقع أثناء التنفيذ، فما قبله نُفِّذ:

```noon
اطبع("قبل")
اطبع(١ / ٠)
اطبع("بعد")
```

```output
قبل
خطأ تشغيل [سطر 2]: القسمة على صفر
```

وفي سطر الأوامر يُعرض السطر المخالف وسهم تحت موضعه، ويخرج البرنامج برمز `1`.

## `ارمِ`

`ارمِ` توقف التنفيذ وترمي قيمة — أي قيمة: نصًّا، أو قاموسًا فيه تفاصيل، أو كائنًا:

```noon
دالة اسحب(الرصيد، المبلغ) {
    إذا (المبلغ > الرصيد) {
        ارمِ {"نوع": "رصيد غير كافٍ"، "الناقص": المبلغ - الرصيد}
    }
    أرجع الرصيد - المبلغ
}

اسحب(١٠٠، ٢٥٠)
```

```output
قيمة مرميّة لم تُلتقط: {"نوع": "رصيد غير كافٍ"، "الناقص": 150}
```

## `حاول` و`امسك` و`أخيرًا`

```noon
دالة اسحب(الرصيد، المبلغ) {
    إذا (المبلغ > الرصيد) { ارمِ "الرصيد لا يكفي" }
    أرجع الرصيد - المبلغ
}

لكل مبلغ في [٣٠، ٥٠٠] {
    حاول {
        اطبع("الباقي:", اسحب(١٠٠، مبلغ))
    } امسك (خطأ_) {
        اطبع("تعذّر سحب", مبلغ، "—", خطأ_)
    } أخيرًا {
        اطبع("انتهت العملية")
    }
}
```

```output
الباقي: 70
انتهت العملية
تعذّر سحب 500 — الرصيد لا يكفي
انتهت العملية
```

- **`امسك (اسم)`** تلتقط القيمة المرميّة في `اسم`. الأقواس اختيارية، والاسم
  كذلك إن لم تحتج إليه: `امسك { … }`.
- **`أخيرًا`** تُنفَّذ في كل الأحوال: نجحت المحاولة، أو أُمسك الخطأ، أو لم يُمسك،
  أو خرجت الدالة بـ`أرجع` من داخل `حاول`.
- لا بدّ من واحدة منهما على الأقل بعد `حاول`.

## أخطاء المُفسِّر تُلتقط أيضًا

القسمة على صفر، والفهرس خارج الحدود، والمتغيّر غير المعرَّف… كلها تُلتقط بـ`امسك`
وتصل **قاموسًا** فيه ثلاثة مفاتيح:

| المفتاح | قيمته |
| --- | --- |
| `نوع` | `"خطأ تشغيل"` |
| `رسالة` | نصّ الخطأ |
| `سطر` | رقم السطر |

```noon
متغير قائمة_ = [١، ٢، ٣]
حاول {
    اطبع(قائمة_[١٠])
} امسك (خ) {
    اطبع(خ["نوع"]، "في السطر", خ["سطر"])
    اطبع(خ["رسالة"])
}
```

```output
خطأ تشغيل في السطر 3
الفهرس 10 خارج الحدود (الطول 3)
```

أما الأخطاء النحوية فلا تُلتقط، لأنها تمنع البرنامج من البدء أصلًا.

## `تحقّق`

`تحقّق(شرط، رسالة؟)` ترمي خطأ تشغيل إن كان الشرط كاذبًا — لافتراضات يجب أن
تصحّ:

```noon
دالة الجذر_الآمن(س) {
    تحقّق(س >= ٠، "لا جذر حقيقي لعدد سالب: " + س)
    أرجع جذر(س)
}

اطبع(الجذر_الآمن(١٦))
اطبع(الجذر_الآمن(-٤))
```

```output
4
خطأ تشغيل [سطر 2]: لا جذر حقيقي لعدد سالب: -4
```
