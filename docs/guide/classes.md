# الأصناف

## صنف وكائن

الصنف قالب للكائنات: يجمع بياناتها (الحقول) وسلوكها (التوابع).

```noon
صنف حساب {
    تهيئة(صاحبه، الرصيد = ٠) {
        هذا.صاحبه = صاحبه
        هذا.الرصيد = الرصيد
    }

    أودع(مبلغ) {
        هذا.الرصيد += مبلغ
        أرجع هذا.الرصيد
    }
}

متغير ح = حساب("هند"، ١٠٠)
ح.أودع(٥٠)
اطبع(ح.صاحبه، ح.الرصيد)
```

```output
هند 150
```

- **`تهيئة`** هو الباني: يُستدعى تلقائيًّا حين تنادي الصنف كدالة، ووسائطه
  وسائط النداء.
- **`هذا`** داخل التابع هو الكائن الذي نُودي عليه.
- **الحقول** تنشأ بالإسناد: `هذا.الرصيد = …` لا تحتاج تصريحًا مسبقًا.
- كلمة `دالة` قبل التابع **اختيارية** داخل الصنف.

الصنف الذي لا `تهيئة` فيه يُنادى بلا وسائط. وقراءة عضو غير موجود خطأ:

```noon
صنف فارغ { }
متغير ك = فارغ()
ك.لون = "أزرق"
اطبع(ك.لون)
اطبع(ك.حجم)
```

```output
أزرق
خطأ تشغيل [سطر 5]: الكائن من الصنف «فارغ» لا يملك «حجم»
```

## الوراثة

`يرث` تجعل الصنف يأخذ توابع صنف آخر، ويعيد تعريف ما يشاء منها. و`الأصل`
تنادي نسخة الأب من التابع:

```noon
صنف موظّف {
    تهيئة(الاسم، الراتب) {
        هذا.الاسم = الاسم
        هذا.الراتب = الراتب
    }
    الدخل() { أرجع هذا.الراتب }
    وصف() { أرجع هذا.الاسم + ": " + هذا.الدخل() }
}

صنف مدير يرث موظّف {
    تهيئة(الاسم، الراتب، العلاوة) {
        الأصل.تهيئة(الاسم، الراتب)
        هذا.العلاوة = العلاوة
    }
    الدخل() { أرجع الأصل.الدخل() + هذا.العلاوة }
}

لكل ش في [موظّف("زيد"، ٤٠٠٠٠)، مدير("هند"، ٦٠٠٠٠، ١٥٠٠٠)] {
    اطبع(ش.وصف())
}
```

```output
زيد: 40000
هند: 75000
```

لاحظ أن `وصف()` المعرَّف في `موظّف` نادى `هذا.الدخل()` فوصل إلى نسخة `مدير`
حين كان الكائن مديرًا: التوابع تُختار بحسب صنف الكائن لا بحسب مكان النداء.

`من_صنف(كائن، صنف)` تفحص الانتماء عبر سلسلة الوراثة كلها:

```noon
صنف أ { }
صنف ب يرث أ { }
اطبع(من_صنف(ب()، أ)، من_صنف(أ()، ب)، نوع(ب()))
```

```output
صحيح خطأ ب
```

## تابع `نص`

الصنف الذي يعرّف تابعًا اسمه `نص` بلا وسائط يُعرض به حين يُطبع أو يُحوَّل نصًّا:

```noon
صنف كسر {
    تهيئة(البسط، المقام) {
        هذا.البسط = البسط
        هذا.المقام = المقام
    }
    نص() { أرجع نص(هذا.البسط) + "/" + نص(هذا.المقام) }
}

متغير ك = كسر(٣، ٤)
اطبع(ك)
اطبع("النتيجة: " + ك)
اطبع([ك، كسر(١، ٢)])
```

```output
3/4
النتيجة: 3/4
[3/4، 1/2]
```

وبدونه يُعرض الكائن هكذا: `<كائن كسر>`.

## التوابع قيم

قراءة التابع دون ندائه تُعطي دالة مربوطة بكائنها، تصلح أن تُمرَّر:

```noon
صنف عدّاد {
    تهيئة() { هذا.القيمة = ٠ }
    زد(مقدار) {
        هذا.القيمة += مقدار
        أرجع هذا.القيمة
    }
}

متغير ع = عدّاد()
اطبع(طبّق(ع.زد، [١، ٢، ٣]))
```

```output
[1، 3، 6]
```
