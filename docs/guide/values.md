# القيم والأنواع

لكل قيمة في «نون» نوع من ثمانية، والدالة `نوع()` تُخبرك به:

```noon
اطبع(نوع(٤٢)، نوع("سلام")، نوع(صحيح)، نوع(عدم))
اطبع(نوع([١، ٢])، نوع({"أ": ١})، نوع(اطبع))
```

```output
عدد نص منطقي عدم
قائمة قاموس دالة
```

| النوع | أمثلة | انظر |
| --- | --- | --- |
| `عدد` | `٤٢`، `3.5`، `٣٫٥`، `-٧` | [العمليات](operators.md) |
| `نص` | `"مرحبًا"`، `'مرحبًا'` | [النصوص](strings.md) |
| `منطقي` | `صحيح`، `خطأ` | |
| `عدم` | `عدم` | |
| `قائمة` | `[١، "ب"، صحيح]` | [القوائم والقواميس](collections.md) |
| `قاموس` | `{"الاسم": "زيد"}` | [القوائم والقواميس](collections.md) |
| `دالة` | `دالة(س) { أرجع س }`، `اطبع` | [الدوال](functions.md) |
| `صنف` | `صنف نقطة { }` | [الأصناف](classes.md) |

والكائن المُنشأ من صنف نوعُه اسمُ صنفه:

```noon
صنف نقطة { }
اطبع(نوع(نقطة())، نوع(نقطة))
```

```output
نقطة صنف
```

## الأعداد

لا تفريق بين صحيح وعشري في النوع: كلاهما `عدد`. تُكتب الأرقام بالعربية-الهندية
أو اللاتينية أو الفارسية، والفاصلة العشرية نقطة أو `٫`، ويُسمح بفاصل الآلاف `٬`
أو `_` للقراءة:

```noon
اطبع(١٢٣ == 123، ٣٫٥ == 3.5، ١٬٠٠٠٬٠٠٠ == 1_000_000)
```

```output
صحيح صحيح صحيح
```

العدد الذي قيمته صحيحة يُطبع بلا كسر، ولو نتج عن عملية عشرية:

```noon
اطبع(١٫٠، ٢٫٥ * ٢، ١ / ٤)
```

```output
1 5 0.25
```

## القيم المنطقية والشروط

`صحيح` و`خطأ` قيمتان منطقيتان. لكن الشرط في `إذا` و`طالما` يقبل أي قيمة، وهذه
وحدها تُعدّ «كاذبة»:

| القيمة | كاذبة لأنها |
| --- | --- |
| `خطأ` | القيمة المنطقية الكاذبة |
| `عدم` | لا قيمة |
| `٠` | صفر |
| `""` | نصّ فارغ |
| `[]` | قائمة فارغة |
| `{}` | قاموس فارغ |

وكل ما عداها صادق. `منطقي(س)` تحوّل أي قيمة إلى `صحيح` أو `خطأ` بهذه القاعدة:

```noon
اطبع(منطقي(٠)، منطقي("٠")، منطقي([])، منطقي([عدم]))
```

```output
خطأ صحيح خطأ صحيح
```

## `عدم`

`عدم` هي «لا قيمة»: قيمة المتغيّر المصرَّح به بلا إسناد، وما تُرجعه دالة بلا
`أرجع`، وما تُرجعه `اطبع`:

```noon
متغير س
دالة لا_شيء() { }
اطبع(س، لا_شيء()، اطبع == عدم)
```

```output
عدم عدم خطأ
```

## التحويل بين الأنواع

| الدالة | تحوّل إلى | مثال |
| --- | --- | --- |
| `نص(س)` | نصّ | `نص(٤٢)` ← `"42"` |
| `عدد(س)` | عدد | `عدد("٣٫٥")` ← `3.5` |
| `منطقي(س)` | منطقي | `منطقي("")` ← `خطأ` |
| `قائمة(س)` | قائمة | `قائمة("نون")` ← `["ن"، "و"، "ن"]` |

`عدد()` تفهم الأرقام العربية في النصّ، وترمي خطأً إن لم يكن النصّ عددًا:

```noon
اطبع(عدد("١٢") + ١)
اطبع(عدد("اثنا عشر"))
```

```output
13
خطأ تشغيل [سطر 2]: لا يمكن تحويل «اثنا عشر» إلى عدد
```
