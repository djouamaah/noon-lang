# الشروط والحلقات

## `إذا` و`وإلا`

```noon
متغير الدرجة = ١٣

إذا (الدرجة >= ١٦) {
    اطبع("ممتاز")
} وإلا إذا (الدرجة >= ١٠) {
    اطبع("ناجح")
} وإلا {
    اطبع("أعِد المحاولة")
}
```

```output
ناجح
```

- الأقواس حول الشرط **اختيارية**: `إذا الدرجة >= ١٦ { … }` صحيحة أيضًا.
- القوسان المعقوفان **إلزاميان** ولو كان في الكتلة سطر واحد.
- `وإلا` يجوز أن تأتي في السطر التالي لـ`}`.
- الشرط يقبل أي قيمة، وقاعدة الصدق في [القيم والأنواع](values.md#القيم-المنطقية-والشروط).

## `طالما`

تكرّر الكتلة ما دام الشرط صادقًا:

```noon
متغير ن = ٢٧
متغير الخطوات = ٠
طالما (ن != ١) {
    إذا (ن % ٢ == ٠) { ن = ن // ٢ } وإلا { ن = ٣ * ن + ١ }
    الخطوات += ١
}
اطبع("وصلنا إلى ١ بعد", الخطوات، "خطوة")
```

```output
وصلنا إلى ١ بعد 111 خطوة
```

## `لكل … في`

تمرّ على عناصر قائمة، أو أحرف نصّ، أو مفاتيح قاموس:

```noon
لكل لون في ["أحمر"، "أخضر"] { اطبع(لون) }
لكل حرف في "نون" { اطبع(حرف) }
لكل مفتاح في {"س": ١، "ص": ٢} { اطبع(مفتاح) }
```

```output
أحمر
أخضر
ن
و
ن
س
ص
```

وللأعداد استعمل `مدى`: `مدى(ن)` من ٠ إلى ن-١، و`مدى(أ، ب)` من أ إلى ب-١،
و`مدى(أ، ب، خطوة)` بخطوة معيّنة ولو سالبة:

```noon
اطبع(مدى(٤)، مدى(٢، ٥)، مدى(١٠، ٠، -٣))
```

```output
[0، 1، 2، 3] [2، 3، 4] [10، 7، 4، 1]
```

وللمرور على المفتاح وقيمته معًا في قاموس:

```noon
متغير الأعمار = {"زيد": ٣٠، "هند": ٢٥}
لكل زوج في الأعمار.عناصر() {
    اطبع(زوج[٠]، "عمره"، زوج[١])
}
```

```output
زيد عمره 30
هند عمره 25
```

!!! note "متغيّر الحلقة جديد في كل دورة"
    كل دورة تصنع متغيّرًا جديدًا، فالدوال المصنوعة داخل الحلقة تتذكّر قيمة
    دورتها لا القيمة الأخيرة. انظر [الإغلاق](functions.md#الإغلاق-closures).

## `توقف` و`استمر`

`توقف` تخرج من أقرب حلقة، و`استمر` تقفز إلى دورتها التالية:

```noon
لكل ن في مدى(١، ٢٠) {
    إذا (ن % ٣ == ٠) { استمر }
    إذا (ن > ١٠) { توقف }
    اطبع(ن)
}
```

```output
1
2
4
5
7
8
10
```
