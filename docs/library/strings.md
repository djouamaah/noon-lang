# نصوص

```noon
متغير ن = استورد("نصوص")
```

تكمل [توابع النصوص المدمجة](../reference/methods.md) (`قص`، `تقسيم`، `استبدل`،
`موضع`…) بما يلزم للنصّ العربي خاصّة: التشكيل، وصور الهمزة، والأرقام الثلاثة
(اللاتينية والعربية-الهندية والفارسية). وكل دالة تُسمّي نفسها في رسالة الخطأ إن
أُعطيت ما لا تقبله.

## الأسطر والكلمات

| الدالة | عملها |
| --- | --- |
| `أسطر(نص)` | الأسطر بلا محارف نهايتها؛ تقبل نهايات ويندوز ولينكس |
| `كلمات(نص)` | متتاليات الحروف والأرقام؛ الترقيم والمسافات تفصل، والتشكيل جزء من الكلمة |
| `عدد_الكلمات(نص)` | طول `كلمات(نص)` |
| `عكس_الكلمات(نص)` | الكلمات بترتيب معكوس بينها مسافة |

```noon
متغير ن = استورد("نصوص")
متغير جملة = "السلامُ عليكم، يا هند! كيف حالُكِ؟"
اطبع(ن.كلمات(جملة))
اطبع(ن.عدد_الكلمات(جملة)، "كلمات")
اطبع(ن.عكس_الكلمات("أنا أحب نون"))
```

```output
["السلامُ"، "عليكم"، "يا"، "هند"، "كيف"، "حالُكِ"]
6 كلمات
نون أحب أنا
```

## النصّ العربي

| الدالة | عملها |
| --- | --- |
| `بلا_تشكيل(نص)` | يحذف الحركات والتنوين والشدّة والسكون والتطويل |
| `وحد_الهمزات(نص)` | أ إ آ ٱ ← ا، وى ← ي، وة ← ه: للبحث لا للعرض |
| `متشابهان(أ، ب)` | هل النصّان واحد بإهمال التشكيل وصور الهمزة والتاء المربوطة؟ |
| `متناظر(نص)` | هل يُقرأ من آخره كما من أوّله؟ بإهمال المسافات والتشكيل والترقيم |
| `أرقام_لاتينية(نص)` | ٠١٢٣ والفارسية ← 0123 |
| `أرقام_هندية(نص)` | 0123 والفارسية ← ٠١٢٣ |

```noon
متغير ن = استورد("نصوص")
اطبع(ن.بلا_تشكيل("مُحَمَّدٌ رَسُولُ اللّٰهِ"))
اطبع(ن.متشابهان("إِسْلام"، "اسلام")، ن.متشابهان("أحمد"، "محمد"))
اطبع(ن.متناظر("حَصَان ناصح"))
اطبع(ن.أرقام_لاتينية("الهاتف: ٠٥٥٥ ١٢٣ ٤٥٦"))
```

```output
محمد رسول الله
صحيح خطأ
صحيح
الهاتف: 0555 123 456
```

البحث في نصّ عربي يحتاج غالبًا إلى إهمال التشكيل والهمزات في الطرفين معًا:

```noon
متغير ن = استورد("نصوص")
متغير أسماء = ["أَحْمَد"، "إيمان"، "آمنة"، "مصطفى"]
دالة ابحث(كلمة) {
    متغير مفتاح = ن.وحد_الهمزات(ن.بلا_تشكيل(كلمة))
    أرجع رشّح(دالة(اسم) { أرجع مفتاح في ن.وحد_الهمزات(ن.بلا_تشكيل(اسم)) }، أسماء)
}
اطبع(ابحث("احمد"))
اطبع(ابحث("امنه"))
```

```output
["أَحْمَد"]
["آمنة"]
```

## فحص المحارف

كلها تُرجع `خطأ` للنصّ الفارغ، وتفحص النصّ كلّه لا أوّل محرف فيه.

| الدالة | عملها |
| --- | --- |
| `هجائي(نص)` | هل كلّه حروف؟ العربية واللاتينية، والتشكيل لا يُخرجه منها |
| `عربي(نص)` | هل كلّه حروف عربية (ومنها ما زادته الفارسية والأردية)؟ |
| `رقمي(نص)` | هل كلّه أرقام؟ من أيّ الأنظمة الثلاثة |
| `مسافة(نص)` | هل كلّه مسافات وأسطر جديدة ومحارف جدولة؟ |

```noon
متغير ن = استورد("نصوص")
اطبع(ن.هجائي("كِتابٌ")، ن.عربي("Noon")، ن.رقمي("٢٠٢٦")، ن.رقمي("١٫٥"))
```

```output
صحيح خطأ صحيح خطأ
```

## الحشو والاقتطاع

| الدالة | عملها |
| --- | --- |
| `حشو_البداية(نص، عرض، [محرف])` | يُطيل النصّ إلى `عرض` بمحارف قبله (يمينه في العربية)؛ الافتراض مسافة |
| `حشو_النهاية(نص، عرض، [محرف])` | بمحارف بعده |
| `توسيط(نص، عرض، [محرف])` | في الوسط؛ الزائد الفردي بعده |
| `اقتطع(نص، حد، [لاحقة])` | `حد` محارف على الأكثر، و`…` في آخره إن قُصّ |

```noon
متغير ن = استورد("نصوص")
متغير بنود = [[٧، "قلم"]، [١٢، "دفتر"]، [١٢٠، "حقيبة مدرسية كبيرة"]]
لكل بند في بنود {
    اطبع(ن.حشو_البداية(نص(بند[٠])، ٤، "0") + " | " + ن.اقتطع(بند[١]، ١٠))
}
اطبع(ن.توسيط(" نون "، ١٢، "="))
```

```output
0007 | قلم
0012 | دفتر
0120 | حقيبة مدر…
=== نون ====
```

## البحث والعدّ

| الدالة | عملها |
| --- | --- |
| `مواضع(نص، مقطع)` | مواضع المقطع كلها دون تداخل، من ٠ |
| `عدد_مرات(نص، مقطع)` | كم مرّة يرد المقطع دون تداخل |
| `تكرار_المحارف(نص)` | قاموس: كل محرف ← عدد مرّاته، بترتيب ظهوره |

```noon
متغير ن = استورد("نصوص")
اطبع(ن.مواضع("نون ونون ونون"، "نون")، ن.عدد_مرات("كتب الكاتب كتابًا"، "كت"))
اطبع(ن.تكرار_المحارف("سلسلة"))
```

```output
[0، 5، 10] 2
{"س": 2، "ل": 2، "ة": 1}
```

## القوالب

`قالب(نص، قيم)` يملأ `{اسم}` في النصّ من قاموس، أو `{٠}` و`{١}`… من قائمة؛
وتُكتب `{{` و`}}` لتظهر الأقواس نفسها.

```noon
متغير ن = استورد("نصوص")
اطبع(ن.قالب("أهلًا يا {اسم}، رصيدك {رصيد} دينارًا."، {"اسم": "هند"، "رصيد": ٢٥٠}))
اطبع(ن.قالب("{٠} × {١} = {٢}"، [٦، ٧، ٦ * ٧]))
اطبع(ن.قالب("{{ليس قالبًا}}"، {}))
```

```output
أهلًا يا هند، رصيدك 250 دينارًا.
6 × 7 = 42
{ليس قالبًا}
```
