# المكتبة القياسية

وحدات تأتي مع «نون» وتُستورد بأسمائها، دون تثبيت شيء:

```noon
متغير ر = استورد("رياضيات")
اطبع(ر.فيبوناتشي(٣٠))
```

```output
832040
```

وهي مكتوبة بـ«نون» نفسها لا بـ Python، في مجلّد `noon/lib/` من المستودع؛ فمن
أراد أن يعرف كيف تعمل دالة منها قرأ شيفرتها بلغته، ومن أراد أن يضيف إليها كتب
بها. وما تفعله [الدوال المدمجة](../reference/builtins.md) يبقى في اللغة نفسها:
المكتبة لما يُبنى فوقها.

| الوحدة | ما فيها |
| --- | --- |
| [`رياضيات`](math.md) | العاملي والتوافيق، القاسم والمضاعف المشترك، الأعداد الأولية، فيبوناتشي، الإحصاء |
| [`نصوص`](strings.md) | الأسطر والكلمات، التشكيل والهمزات والأرقام الثلاثة، فحص المحارف، الحشو والاقتطاع، القوالب |

كيف تُستورد الوحدات وتُكتب: [الوحدات](../guide/modules.md).
