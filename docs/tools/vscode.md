# إضافة VS Code

في المستودع إضافة جاهزة لـ Visual Studio Code في
[`editors/vscode/`](https://github.com/djouamaah/noon-lang/tree/main/editors/vscode).
الألوان في أمثلة هذا الموقع تأتي من **قواعد الإضافة نفسها**، فما تراه هنا
تراه في محرّرك.

## التثبيت

الإضافة ملفات تعريف فقط، لا تحتاج بناءً ولا `npm`. انسخ مجلّدها إلى مجلّد إضافات
VS Code ثم أعِد تشغيل المحرّر:

=== "ويندوز"

    ```bash
    xcopy /E /I editors\vscode "%USERPROFILE%\.vscode\extensions\noon-lang-1.2.0"
    ```

=== "لينكس وماك"

    ```bash
    cp -r editors/vscode ~/.vscode/extensions/noon-lang-1.2.0
    ```

=== "ملف ‎.vsix"

    نزّل `noon-lang-1.2.0.vsix` من [صفحة الإصدار](https://github.com/djouamaah/noon-lang/releases/latest)،
    ثم:

    ```bash
    code --install-extension noon-lang-1.2.0.vsix
    ```

    أو ابنِه بنفسك: `cd editors/vscode && npx @vscode/vsce package`.

بعدها يُفتح كل ملف `.noon` أو `.نون` ملوَّنًا.

## ما فيها

| الوجه | التفصيل |
| --- | --- |
| **تلوين الصيغة** | الكلمات المفتاحية، والنصوص وتهريباتها، والأعداد بكل أرقامها، والتعليقات، وأسماء الأصناف والدوال عند تعريفها، والدوال المدمجة، وتوابع الأنواع |
| **مقاطع جاهزة** | اكتب أوّل الكلمة واضغط ++tab++ |
| **الأقواس** | إغلاق تلقائي لـ`{ [ ( " ' «`، وإزاحة ذكية بعد `{` |
| **التعليقات** | ++ctrl+slash++ يعلّق السطر بـ`#` |
| **حدود الكلمة** | النقر المزدوج يختار الاسم العربي كاملًا بتشكيله |
| **الطيّ** | بين `# منطقة` و`# نهاية` |

### المقاطع الجاهزة

| اكتب | تحصل على |
| --- | --- |
| `دالة` | تعريف دالة |
| `دالة مجهولة` | `دالة(س) { أرجع … }` |
| `صنف` | صنف مع `تهيئة` و`نص` |
| `صنف يرث` | صنف ابن ينادي `الأصل.تهيئة` |
| `إذا`، `إذا وإلا` | شرط |
| `لكل`، `لكل مدى`، `طالما` | حلقات |
| `حاول` | `حاول { } امسك (خطأ_) { }` |
| `متغير`، `ثابت`، `اطبع` | اختصارات |

ولكل مقطع اسم لاتيني بديل (`dala`، `sinf`، `itha`…) لمن لم يبدّل لوحة المفاتيح.

## قواعد التلوين مولَّدة

ملف القواعد `noon.tmLanguage.json` **لا يُحرَّر يدويًّا**: يُولَّد من جداول
الكلمات المفتاحية والدوال المدمجة في المُفسِّر نفسه:

```bash
python tools/build_grammar.py
```

فإذا أُضيفت دالة مدمجة إلى اللغة وأُعيد التوليد، لُوِّنت تلقائيًّا. والاختبارات
تفشل إن نُسي التوليد، وتتحقّق أن كل كلمة مفتاحية ملوَّنة وأن الأسماء الشبيهة
بها (`صنّف`، `أرجعه`) ليست كذلك.

لمعاينة التلوين في المتصفّح دون تثبيت شيء:

```bash
python tools/preview_highlight.py examples/shapes.noon -o معاينة.html
```

## حدود معروفة

- **اتجاه السطر.** VS Code ليس محرّرًا عربيًّا كاملًا؛ يعرض كل سطر بخوارزمية
  الاتجاه الثنائي، فقد يبدو موضع `{` أو `(` غريبًا في سطر يخلط العربية
  باللاتينية. الشيفرة نفسها صحيحة، والعرض وحده يتأثّر.
- **الوسائط** لا تُلوَّن لونًا خاصًّا، كما في أغلب لغات VS Code.
- **لا خادم لغة بعد**: لا تكملة ذكية ولا انتقال إلى التعريف ولا أخطاء أثناء الكتابة.
